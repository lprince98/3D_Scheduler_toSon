주 사용 기기는 **태블릿** (네오탭 Z11 Plus, 안드로이드 크롬) — **형(초5)과 같은 태블릿 한 대**를 같이 쓴다.

## 0. 몬스터·전차 버전과 다른 점 (요약)

대상은 **만 4세, 한글을 아직 못 읽는 아이**다. 그래서 아이가 보는 화면에는 **글자를 하나도 두지 않는 것**을 목표로 한다. 뭘 해야 하는지는 그림, 소리, 손가락 안내 애니메이션으로만 알려 준다. 시간 개념이 약하고 며칠 뒤의 보상은 기다리기 어렵다는 점, 손끝 조작이 서툴다는 점도 전제로 했다.

| 항목 | 몬스터 3D / 전차 (초5) | 공룡 (만 4세) |
|---|---|---|
| 글자 | 미션 이름·분량을 글로 표시 | **아이 화면에 글자 없음.** 그림 아이콘 + 카드를 누르면 소리로 읽어 줌 + 손가락 안내 애니메이션 |
| 완성 주기 | 한 달 = 1마리(1대) | **4~5일 = 1마리** (뼈 조각 8개) |
| 보상 단위 | 미션 1개 = 성장 1번 / 부품 1개 | 미션 1개 = **뼈 조각 1개를 캐내 직접 끌어다 붙이기** |
| 진화 조건 | 주간 80% 달성 | **없음.** 조각을 다 모으면 무조건 깨어남 (비율·숫자 개념 불필요) |
| 미션 시간 | 5~60분, 기본 20분 | **타이머 없음 또는 5~20분, 기본 10분** |
| 타이머 표시 | 원형 타이머 + 숫자 | **숫자 없는 발자국 타이머** (발자국이 하나씩 사라짐) |
| 미션 종류 | 숙제 (수학·영어·구몬 등) | 놀이 학습 + **생활 습관** (양치·정리·책 읽기 등) |
| 완료 확인 | 아이가 "다 했어!" | 아이가 "다 했어!" + (선택) **부모 확인 도장** |
| 이름 짓기 | 아이가 입력 | 그림 카드를 누르면 이름을 들려줌 → 마음에 드는 카드 고르기 (부모가 입력도 가능) |
| 앱 안에서 놀기 | 탭 반응 하루 30회 | 탭 30회 + **3분 동안 할 일을 안 하면 공룡이 잠듦** |
| 데이터 | `monsterPlanner3D` / `tankPlanner` | localStorage `dinoPlanner` — 완전히 별도 (같은 태블릿이므로 7.1 주의) |

핵심 원칙은 그대로다: 미션 1개 = 보상 1번 즉시, 벌칙·감점·퇴화 없음, 미션은 부모가 전부 등록, 게임이 할 일보다 커지지 않게.

## 1. 한 줄 요약

한글을 못 읽는 만 4세 아이가 매일의 할 일(양치·정리·책 읽기 등)을 스스로 시작하도록, 할 일을 하나 끝낼 때마다 공룡 뼈 화석을 하나 캐내 직접 붙이고, 뼈가 다 모이면 공룡이 **살아나서 움직이는** 태블릿 웹앱.

## 2. 사용자

| 역할 | 설명 | 핵심 니즈 |
|---|---|---|
| 아이 (주 사용자) | 만 4세, 한글 못 읽음, 공룡을 좋아함. 형과 태블릿을 같이 씀 | 글 없이도 뭘 해야 하는지 알 것, 보상이 바로 올 것, 손으로 직접 만지는 재미 |
| 부모 (관리자) | 할 일 등록, 완료 확인, 진행 확인. 대부분의 할 일을 옆에서 같이 함 | 등록이 간단할 것, 형 앱과 섞이거나 서로 망가뜨리지 않을 것 |
| 형 (초5) | 같은 태블릿에서 몬스터·전차 앱 사용 | 동생이 형 앱의 진행을 건드리지 않을 것 (7.1) |

## 3. 목표와 비목표

**목표**
- 아이가 **글자를 전혀 몰라도** 오늘 할 일을 알아보고 스스로 "시작"을 누른다.
- 할 일 1개를 끝낼 때마다 10초 안에 손에 잡히는 보상(뼈 조각)을 받는다.
- 4~5일이면 공룡 한 마리가 완성되는 짧은 목표를 준다.
- "내가 뼈를 모아서 살려낸 공룡"이라는 애착을 만든다.

**비목표**
- 공룡 배틀·먹이 주기·탐험 등 게임 요소 (앱이 놀이 시간이 되는 것 방지)
- 뼈 조립을 퍼즐처럼 어렵게 만드는 것 (틀려서 좌절하는 구조 금지)
- 한글·숫자 교육 기능 (앱은 할 일 습관용. 학습은 부모가 등록한 할 일 안에서)
- 특정 만화·완구 캐릭터를 닮은 공룡 (저작권 문제 + 앱만의 공룡이어야 애착이 생김)
- 외부 3D 모델 파일, 녹음을 서버로 보내는 것, 광고·외부 링크
- 형(초5) 앱과의 데이터 연동

## 4. 핵심 규칙

| 항목 | 규칙 |
|---|---|
| 완성 주기 | 공룡 1마리 = 뼈 조각 **8개** (부모가 8 / 12 중 선택). 하루 2개씩이면 4~5일 |
| 조각 획득 | 미션 1개 완료 = 뼈 조각 1개. 하루치를 다 하면 공룡이 춤추는 짧은 연출 + 발자국 도장 1개 |
| 조각 순서 | 공룡마다 정해진 순서 (몸통 → 다리 → 머리 → 꼬리 식). 아이가 고르지 않음 |
| 깨어남 | 조각을 다 붙이면 즉시 "공룡이 깨어나요" 연출. 달성률 조건 없음 |
| 못 한 날 | 아무 일도 없음. 조각이 안 늘 뿐, 뺏기거나 흩어지지 않음 |
| 월간 보상 | 한 달에 완성한 공룡 수만큼 스티커 배지 (1~6마리 단계). 모자란 달도 모은 만큼 받음 |
| 미션 등록 | 부모가 전부 등록. 매주 반복 + 날짜별 수정 (몬스터·전차 앱과 동일) |
| 하루 미션 수 | 부모가 정한 만큼, 최대 **3개** |
| 미션 시간 | 미션마다 "타이머 없음" 또는 5~20분 (5분 단위), 기본 10분 |
| 부모 확인 | 미션마다 켜고 끌 수 있음. 정리·양치 아이콘은 처음부터 켜짐, 나머지는 꺼짐 |
| 탭 반응 | 공룡 탭 반응 하루 30회 (몬스터 앱과 같은 임시값) |
| 공룡 잠자기 | 홈에서 할 일을 시작하지 않고 **3분**이 지나면 공룡이 하품하고 잠듦 (탭 반응 멈춤, 할 일 카드는 그대로 누를 수 있음). 할 일을 하나 끝내면 깨어남 |

### 4.1 기본 미션 아이콘 (부모가 추가·변경, 최대 12개)

| 아이콘 | 소리로 읽어 줄 이름 | 비고 |
|---|---|---|
| 칫솔 | 양치하기 | 타이머 없음, 부모 확인 켜짐 |
| 장난감 상자 | 정리하기 | 부모 확인 켜짐 |
| 책 | 책 읽기 | 부모와 함께 |
| 크레파스 | 그림 그리기 | |
| 연필과 선 | 선 긋기·따라 그리기 | 학습지 대용 |
| 퍼즐 조각 | 퍼즐·블록 | |
| 옷 | 혼자 옷 입기 | 타이머 없음 |
| 숟가락 | 밥 잘 먹기 | 타이머 없음 |
| 공 | 몸 놀이 | |
| 별 | 기타 | |

- 아이콘은 이모지 대신 **앱에 넣은 단순한 그림(SVG)** 으로 그린다. 기기마다 이모지 모양이 달라 아이가 헷갈릴 수 있다. 글자(ㄱㄴ, 123, ABC)를 그림으로 쓰는 아이콘은 넣지 않는다 — 못 읽는 아이에게는 무늬일 뿐이라 구별이 안 됨.
- 아이콘마다 색 1개 (화석 바위 색으로 쓰임). 색이 달라야 아이가 카드를 구별하기 쉽다.

## 5. 3D 공룡 설계

### 5.1 스타일
- 로우폴리·장난감 느낌. 큰 머리, 짧은 다리, 둥근 눈 — **무섭지 않게** (이빨은 작고 둥글게, 입은 웃는 모양)
- 뼈 상태: 아이보리색 뼈 + 빈자리는 점선 윤곽(실루엣)으로 "여기 붙여" 표시
- 깨어난 상태: 뼈 위로 무광 파스텔 피부. 몸 색 + 무늬 색 2가지
- 배경: 발굴 현장(모래색 바닥 + 단순한 바위 몇 개). 깨어난 뒤에는 풀밭 색으로 바뀜

### 5.2 공룡 목록

1차 3종:

| 공룡 | 특징 | 8조각 구성 |
|---|---|---|
| 티라노사우루스 | 큰 머리, 짧은 앞다리 | 몸통(등뼈·갈비), 골반, 왼 뒷다리, 오른 뒷다리, 앞다리 한 쌍, 머리, 아래턱, 꼬리 |
| 트리케라톱스 | 뿔 3개, 목 프릴 | 몸통, 골반, 앞다리 한 쌍, 뒷다리 한 쌍, 꼬리, 목 프릴, 머리, 뿔 |
| 스테고사우루스 | 등판, 꼬리 가시 | 몸통, 골반, 앞다리 한 쌍, 뒷다리 한 쌍, 목과 머리, 등판 앞, 등판 뒤, 꼬리 가시 |

- 12조각 설정이면 다리·꼬리·등판을 더 잘게 나눈다 (공룡마다 12조각 목록을 따로 정의).
- 공룡 이름은 고를 때와 완성할 때 소리로 들려준다. 아이가 이름을 따라 부르는 것만으로 충분.

2차 (5단계): 브라키오사우루스, 안킬로사우루스, 스피노사우루스, 파라사우롤로푸스, 프테라노돈(※ 엄밀히 공룡은 아니지만 아이들이 공룡으로 앎 — 넣을지 부모 판단)

- 첫 마리를 완성하면 다음 공룡 2~3종 그림 카드 중 아이가 고름 (고르는 재미는 여기서만)
- 같은 공룡을 또 골라도 됨 (색만 다르게)

### 5.3 조각 1개를 붙이는 흐름 (핵심 상호작용, 10초 이내)

1. 미션 완료 → 화면 가운데에 **화석 바위** 등장 (아이콘 색)
2. 손가락 그림이 바위를 두드리는 모습을 보여 줌 → 아이가 **톡톡톡 3번** 두드리면 깨지면서 뼈 조각이 나옴 (파티클 10개 이하)
3. 공룡 뼈대의 **빈자리 하나가 반짝임** + 손가락 그림이 뼈에서 빈자리로 끄는 모습을 보여 줌
4. 아이가 뼈를 끌어다 반짝이는 자리 근처에 놓으면 **착 달라붙음** (자석 효과. 판정 범위를 아주 넓게 — 화면 폭의 1/4)
5. 5초 동안 못 붙이면 뼈가 스스로 날아가 붙음 (좌절 방지). 두드리기도 5초 안 하면 자동으로 깨짐
6. "딸깍" 소리 + 뼈대 전체가 한 번 반짝 + 아래 뼈 칸 하나가 채워짐 (숫자·글자 없이)

- 손가락 안내 애니메이션은 처음 몇 번만 바로 나오고, 익숙해지면(연속 3번 스스로 성공) 2초 기다렸다가 나온다.
- 바위 두드리기·끌어다 놓기는 "내가 했다"는 느낌을 주기 위한 것. 더 늘리지 않는다.

### 5.4 깨어남 연출 (약 6초, 부모 모드에서 건너뛰기 설정 가능)

1. 뼈대가 빛에 감싸짐 (빛 기둥은 이미지 한 장으로 흉내)
2. 뼈 위로 피부가 아래에서 위로 차오름 (재질 전환)
3. 눈을 깜빡 → 기지개 → "크앙!" (Web Audio로 만든 **귀여운** 울음소리. 낮고 무서운 소리 금지)
4. 제자리에서 통통 두 번 뛰고 풀밭 배경으로 전환
5. 이어서 **꾸미기 화면**: 몸 색 / 무늬 색 / 무늬 종류(점·줄·없음)를 큰 동그라미로 고름 → 이름 카드 고르기 (카드를 누르면 이름을 들려줌, 한 번 더 누르면 결정)

### 5.5 움직임 (깨어난 공룡)
- 대기: 몸 흔들기, 꼬리 좌우, 3~5초마다 눈 깜빡
- 탭: 통통 뛰며 "크앙" (하루 30회 제한, 넘으면 졸린 표정으로 "쿨쿨" — 벌칙 느낌 없이)
- 드래그: 한 손가락 좌우 회전만. 확대·위아래 회전 막음
- 뼈 상태(조립 중)에서도 좌우 회전 가능
- 잠자기(4절): 눈 감고 숨 쉬듯 천천히 움직임, 화면을 살짝 어둡게. 렌더링을 초당 몇 프레임으로 낮춰 배터리 절약

## 6. 화면

공통 규칙 (몬스터 3D 버전 6절 그대로) + 만 4세용 추가:
- **아이가 보는 화면에는 글자를 두지 않는다.** 모든 안내는 그림·소리·애니메이션으로. (부모 모드는 예외)
- 버튼 최소 **72px**, 한 화면에 누를 수 있는 것 최대 5개
- 버튼 종류는 딱 두 가지 모양으로 통일: **시작(초록 ▶)**, **다 했어(노란 ✓ + 엄지척 공룡)**. 모양만 보고 알 수 있게
- 빨간색 경고, 실패를 뜻하는 소리·표정 쓰지 않음
- 뒤로 가기·새로고침·앱 전환 뒤에도 같은 화면으로 돌아옴 (상태는 즉시 저장)

### 6.1 홈 (아이)
- 앱을 열면 공룡이 인사하고 오늘 할 일을 소리로 알려 줌 ("오늘은 양치하기랑 책 읽기를 하자!" — 부모 녹음이 있으면 그 목소리)
- 가운데: 3D 공룡 (조립 중이면 뼈대 + 빈자리 실루엣, 완성이면 살아 있는 공룡)
- 아래: 뼈 칸 8개 — 뼈 모양, 모은 만큼 채워짐 (숫자 없음)
- 오늘 할 일 카드 (최대 3개) — 큰 그림 아이콘 하나 + 시작 버튼. **카드를 누르면 이름을 소리로 읽어 줌**, 시작 버튼을 누르면 시작. 끝난 카드는 발자국 도장이 찍히고 흐려짐
- 할 일이 없는 날: 달과 잠자는 공룡 그림 + "오늘은 쉬는 날이야" 소리
- 한 번도 등록 안 했으면: 공룡이 기다리는 그림만 (부모가 볼 안내 문구는 부모 모드 입구 옆에 작게)
- 오른쪽 위 공룡 발자국 = 공룡 공원(도감) 입구
- 부모 모드 입구는 **왼쪽 위 모서리 3초 길게 누르기** (버튼은 보이지 않게. 아이가 우연히 들어가도 비밀번호에서 막힘)

### 6.2 집중 모드
- 할 일 그림 + **발자국 타이머**: 발자국 10개가 일정 간격으로 하나씩 사라짐. 숫자 없음
- 시작할 때 할 일 이름을 한 번 더 들려줌
- 마지막 발자국이 사라지면 공룡 그림이 손짓 (소리 + 진동)
- "잠깐" (일시정지, ⏸ 그림) / "나중에" (집 그림, 홈으로. 벌칙 없음)
- "타이머 없음" 미션은 발자국 없이 바로 큰 "다 했어" 버튼만
- 타이머보다 일찍 끝냈어도 "다 했어"를 누를 수 있음 (유치원생 할 일은 분량이 기준. 부모 확인으로 보완)
- 3D 렌더링 정지, 공룡은 정지된 작은 그림으로 구석에만 (몬스터 앱과 동일)
- 화면 꺼짐 방지

### 6.3 부모 확인 도장 (미션별로 켰을 때만)
- "다 했어" → 공룡이 도장을 들고 기다리는 그림 + "엄마 아빠한테 보여 주자!" 소리
- 부모는 **간단한 계산 문제**(예: 14 + 9)를 풀어 도장을 찍음. 만 4세가 스스로 풀 수 없고, 부모는 비밀번호보다 빠름
- 형이 대신 풀어 줄 수도 있음 → 부모 모드에서 계산 문제 대신 부모 비밀번호로 바꾸는 설정 제공
- 도장 찍으면 화석 바위 등장 (5.3). 부모가 바로 못 보면 "나중에" → 홈 카드에 도장 기다리는 그림 표시, 조각은 도장 받을 때 나옴

### 6.4 공룡 공원 (도감)
- 완성한 공룡 카드 목록 (썸네일 = 완성 시점 캡처). 카드를 누르면 이름을 들려주고, 한 번 더 누르면 3D로 보기 (한 번에 1마리만 렌더링)
- 아직 안 연 공룡은 물음표 실루엣
- 이번 달 스티커 배지

### 6.5 첫 실행
1. 부모가 먼저 비밀번호 설정 + 할 일 등록 (+ 녹음) — 부모 모드부터 시작
2. 아이 차례: 공룡 3종 그림 카드 (누르면 이름을 들려줌) 중 하나 고르기 → 발굴 현장에 빈 뼈대 실루엣 등장
3. 첫 조각은 **선물로 1개** 줌 → 손가락 안내를 따라 5.3 흐름을 바로 체험 (설명 없이 익힘)

### 6.6 부모 모드 (몬스터·전차 앱과 같은 구성 + 유치원 항목)
- 비밀번호 6자리, 미션 등록(매주 반복 / 날짜별), 달성률, 설정, 테스트·초기화, 데이터 내보내기/가져오기 — 기존 구성 그대로
- 미션 항목에 추가: 아이콘 선택, **타이머 없음**, **부모 확인** 켜기/끄기, **녹음** (아래)
- 설정에 추가: 공룡 1마리 조각 수(8/12), 깨어남 연출 건너뛰기, 잠자기 시간(3분 기본, 끄기 가능), 부모 확인 방식(계산 문제 / 비밀번호), 이름 카드 목록 편집
- **부모 목소리 녹음 (3단계에 포함)**: 글을 못 읽는 아이에게는 이 기능이 사실상 메뉴판이다.
  - 아이콘마다 이름 녹음 ("양치하자~") — 최대 5초
  - 앱 시작 인사 녹음 (선택)
  - 녹음이 없는 아이콘은 음성 합성으로 읽음 (7.2)
  - 녹음은 이 태블릿 안에만 저장

## 7. 기술

기본은 PRD-3D.md 7절과 같다 (Three.js를 파일 안에 묶어 넣음, index.html 하나, Web Audio 효과음, PWA + 서비스워커, 성능 필수 조건 전부). 다른 점만 적는다.

### 7.1 형 앱과 한 태블릿에서 같이 쓰기

세 앱(몬스터·전차·공룡)은 모두 `lprince98.github.io` 주소 아래에 있다. 브라우저 입장에서는 **같은 사이트**라 저장 공간을 같이 쓴다. 그래서 아래를 지킨다.

| 항목 | 규칙 |
|---|---|
| 저장 키 | localStorage `dinoPlanner`, 녹음은 IndexedDB `dinoPlannerVoice`. 다른 앱 키는 읽지도 쓰지도 않음 |
| 초기화 | "모든 데이터 지우기"는 **자기 키만** 지운다. `localStorage.clear()` 같은 전체 삭제 금지 — 쓰면 형의 몬스터·전차 진행까지 날아감. 몬스터·전차 앱도 자기 키만 지우는 것을 확인함 (11절) |
| 서비스워커 | scope `dinosaurus/`, 캐시 접두어 `dino3d-`. 다른 앱 캐시는 지우지 않음 |
| 홈 화면 아이콘 | 공룡 발자국 모양, 초록·노랑 계열로 형 앱 아이콘과 확실히 다르게. 공룡 아이콘은 첫 페이지 아래쪽, 형 앱들은 다른 페이지나 폴더에 두기를 README에 권장 |
| 부모 비밀번호 | 앱마다 따로 저장 (데이터 분리 원칙). 부모가 같은 번호로 정하면 편함 — 자동 공유는 하지 않음 |
| 용량 | 녹음은 5초 이하, 저품질(모노) 저장. 아이콘 12개 + 인사 = 1MB 이하 |
| 첫 화면 | 저장소 루트의 앱 선택 화면에 공룡 추가 (그림만으로 구별되게) |

동생이 형 앱을 열어 "다 했어"를 누르는 사고는 이 문서로 막을 수 없다. 형 앱 쪽 대책은 11절에 적었다.

### 7.2 읽어주기
- 1순위: 부모 녹음
- 2순위: 브라우저 음성 합성(Web Speech API, ko-KR). 안드로이드 크롬에서 한국어 음성 데이터가 기기에 깔려 있어야 오프라인에서도 됨 → **0단계 필수 확인**
- 둘 다 안 되면: 소리 없이 그림과 손가락 안내만으로도 흐름이 끊기지 않게 설계 (소리는 도움이지 필수 경로가 아님)
- 효과음과 목소리는 볼륨을 따로 두지 않고, 목소리가 나오는 동안 효과음을 줄임

### 7.3 입력
- 드래그(뼈 붙이기)는 포인터 이벤트로 처리. 붙이는 판정은 화면상 거리로 계산 (3D 정밀 판정 안 함)
- 두 손가락 이상 동시 터치는 무시 (만 4세는 손바닥·다른 손가락이 화면에 닿는 일이 많음). 첫 번째 손가락만 따라감
- 빠른 연타로 버튼이 두 번 눌리지 않게 (시작·다 했어는 누른 뒤 1초 잠금)

### 7.4 성능
- 폴리곤 예산: 공룡 1마리 **3,000 삼각형 이하** (화면에 보이는 상태 기준). 뼈는 캡슐·원기둥 저분할로
- 뼈대 상태와 피부 상태는 같은 그룹 구조를 공유하고 재질·형태만 바꿔서 모델 2벌 관리를 피함
- 빈자리 실루엣은 반투명 대신 **점선 외곽선 텍스처** (반투명 겹침이 보급형 GPU에서 가장 느림)
- 파티클은 바위 깨짐·깨어남 연출 동안만, 30개 이하
- 잠자기 상태에서는 렌더링을 크게 낮춤 (4절)

## 8. 개발 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 0 | 티라노 1종 프로토타입: 뼈대 ↔ 깨어난 상태 전환, 대기 동작, 좌우 회전, **뼈 1개 두드려 캐내고 끌어다 붙이기**, 한국어 음성 합성 테스트 버튼 | 아이가 손가락 안내만 보고(부모 설명 없이) 뼈를 붙인다. "또 할래" 반응. 실기기에서 음성 합성이 인터넷 없이 나오는지 확인 |
| 1 | 홈 + 할 일 카드(아이콘·소리) + 미션 완료 → 바위 깨기 → 뼈 붙이기 8조각 + 잠자기. 공룡 고르기는 5단계로 옮김 (티라노 1종뿐이라 고를 게 없음). 할 일 등록은 3단계 전까지 테스트 패널의 "매일 할 일"로 임시 | 아이가 하루 할 일 2개를 끝내고 조각 2개를 스스로 붙인다 |
| 2 | 집중 모드 발자국 타이머 + 타이머 없음 미션 + 3D 정지/재개 + 효과음·진동 | 실제 할 일 1회를 타이머로 끝까지 |
| 3 | 부모 모드 (기존 앱 이식 + 아이콘·타이머 없음·부모 확인 도장·**녹음**) + 7.1 저장 분리 점검 | 부모가 한 주 할 일 등록·녹음, 부모 확인 미션 1회 동작. 공룡 앱 초기화 후 형 앱 데이터가 그대로인지 확인 |
| 4 | 깨어남 연출 + 꾸미기 + 이름 카드 + 공룡 공원 + 배지 | 1마리 완주 시나리오 동작 (부모 모드 "테스트"로 조각 채우기 가능) |
| 5 | 트리케라톱스·스테고사우루스 + 공룡 고르기 화면, 이후 2차 공룡 | 3종 완주 |

**구현 상태 (0.3)**: 0~5단계 모두 구현. PC 브라우저(가로·세로)에서 전체 흐름 확인, 실기기·아이 반응은 아직.
- 공룡 고르기는 첫 실행과 공룡을 완성할 때마다 나옴 (카드를 누르면 이름을 들려주고, 초록 ✓로 결정. 이름 카드·공원도 같은 방식)
- 보류: 공룡 1마리 12조각 설정 (8조각 고정), 2차 공룡
- 부모 녹음은 3단계에 포함 (할 일 이름 + 인사)

0단계에서 반드시 볼 것: 만 4세 손으로 **끌어다 놓기가 실제로 되는지**. 안 되면 "뼈를 탭하면 날아가 붙는" 방식으로 바꾸고 나머지 단계를 진행한다.

## 9. 성공 지표 (한 달 후)

- 아이가 부모가 말하기 전에 앱을 열고 할 일 카드를 누르는 날이 주 4일 이상
- 부모 도움 없이 할 일 그림을 보고 뭘 해야 하는지 말할 수 있다
- 공룡 4마리 이상 완성
- 아이가 공룡 공원을 보여 주며 공룡 이름을 부른다 / "다음엔 뭐 살릴까" 이야기한다
- 공룡 만지는 시간이 할 일 시간보다 길어지지 않는다 (부모 체감 + 잠자기 기능)
- 형 앱 진행이 동생 때문에 망가진 일이 없다

## 10. 확정 사항

1. 몬스터·전차 앱과 같은 기술 기반·부모 모드 구성, 데이터는 완전히 별도
2. 대상 만 4세, 한글 못 읽음 → 아이 화면에 글자 없음. 그림 + 소리 + 손가락 안내만
3. 1마리 = 뼈 조각 8개(12개로 조절 가능), 달성률 조건 없이 다 모으면 깨어남
4. 미션 1개 = 조각 1개 즉시, 벌칙 없음. 하루 최대 3개, 기본 10분
5. 뼈 붙이기는 직접 끌어다 놓기, 5초 뒤 자동 완료로 좌절 방지
6. 부모 목소리 녹음을 3단계 필수 기능으로 포함
7. 형과 같은 태블릿 사용 → 같은 사이트 저장 공간을 공유하므로 자기 키만 읽고 쓰고 지움
8. 특정 캐릭터를 닮지 않은 앱 고유의 귀여운 공룡
