## 태블릿에서 여는 법
1. 저장소를 GitHub에 올리면(push) 1~2분 뒤 `https://lprince98.github.io/3D_Scheduler_toSon/dinosaurus/` 에서 열림
2. 크롬 메뉴 ⋮ → "홈 화면에 추가". 형 앱 아이콘과 다른 페이지에 두기를 권장
3. **처음 할 일**: 왼쪽 위 모서리 3초 → 비밀번호 6자리 정하기(두 번) → "할 일" 탭에서 요일별로 넣기

## 아이 화면 흐름
1. **공룡 고르기** (첫 실행, 공룡을 완성할 때마다): 티라노·트리케라톱스·스테고사우루스 카드 → 누르면 이름을 들려주고 커짐 → 초록 ✓
2. **홈**: 공룡 뼈대 + 오늘 할 일 카드(가로=오른쪽, 세로=아래). 그림을 누르면 이름을 읽어 줌, 초록 ▶로 시작
3. **하는 중**: 큰 그림 + 발자국 10개 타이머(숫자 없음, 하나씩 사라짐) + ⏸ 잠깐 + 🔊 + 집(나중에) + 노란 ✓(다 했어). 3D는 멈추고 화면은 꺼지지 않음. 시간이 다 되면 공룡이 손짓하고 딩동
4. **부모 확인 도장** (도장 켠 할 일만): 두 자리 덧셈 또는 비밀번호. "나중에"면 카드에 노란 도장 버튼이 남음
5. **바위 → 뼈**: 할 일 색깔 바위를 톡톡톡 → 뼈를 반짝이는 자리로 끌어다 놓기. 5초 동안 못 하면 저절로
6. **깨어남** (뼈 8개): 빛 → 피부가 차오름 → 크앙 → 풀밭 → **꾸미기**(몸 색·무늬 색·점/줄/없음) → **이름 카드** 6장 중 고르기
7. **공룡 공원** (오른쪽 위 발자국 버튼): 완성한 공룡 사진, 이번 달 별 스티커(6칸), 누르면 이름을 들려주고 ▶로 3D 보기. 아직 못 만든 공룡은 ?
8. 깨어난 공룡이 있는 상태에서 다음 할 일을 끝내면 그 공룡은 공원으로 가고, 새 공룡을 고름
- 오늘 할 일을 다 하면 "오늘 할 일 다 했어! 최고야!", 처음 만질 때 인사
- 할 일을 안 하고 3분(설정 가능) → 공룡이 잠듦. 할 일을 끝내면 깨어남
- 깨어난 공룡을 톡 치면 뛰고, 가끔 "나는 ○○야!" (하루 30번)

## 부모 모드 (왼쪽 위 모서리 3초 → 비밀번호)
PC에서는 주소 끝에 `#test`를 붙이면 ⚙ 버튼이 보이고 한 번 누르면 비밀번호 화면. 위쪽 막대의 "앱 선택"으로 첫 화면(몬스터·전차·공룡 고르기)으로 갑니다 (아이 화면에는 일부러 넣지 않음).
| 탭 | 내용 |
|---|---|
| 할 일 | 매주 반복(요일별) / 날짜별(주 이동, "이 날만"·"반복으로", 지난주 복사, 반복으로 되돌리기, 이번 주 비우기). 하루 최대 3개, 할 일마다 시간(5~20분)·타이머 끄기·도장 |
| 할 일 종류 | 이름(읽어 줄 말)·아이콘 10종·색·기본값, 최대 12개. **이름 녹음**(5초, 녹음이 음성 합성보다 먼저), 인사 녹음 |
| 달성 | 오늘·이번 주·이번 달 %, 최근 7일 막대, 할 일별 최근 4주, 공룡·아이 기록 |
| 설정 | 기본 시간, 잠자기, 도장 방식, 붙이는 방식, 깨어남 연출 짧게, 소리, 이름 카드 6개, 3D 품질, 성능 표시, 비밀번호 바꾸기 |
| 테스트 | 뼈 주기, 7개 채우기, 깨어남 보기, 지금 공룡 처음부터, 오늘 다시 만들기, 재우기, 읽어주기 테스트, 모든 데이터 지우기(두 번 눌러야 함, 비밀번호 유지) |
| 데이터 | JSON 파일 저장 / 글자로 보기 / 가져오기 (녹음은 제외) |
