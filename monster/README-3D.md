## 미션은 부모가 전부 등록 (v7)

- 앱이 스스로 만드는 미션은 없습니다. 처음 설치하면 홈에 "아직 미션이 없어요 — 부모님이 등록하면 여기에 나와요"가 뜨고, 부모 모드는 "매주 반복" 화면으로 열립니다
- **매주 반복**: 요일별 미션 목록(과목·분량·시간, 하루 최대 5개). 매주 자동으로 반복. 비워 둔 요일은 쉬는 날
- **날짜별**: 특정 날짜만 바꿀 때. 고친 날은 "이 날만", 안 고친 날은 "반복"으로 표시. "반복으로"(하루) / "반복 일정으로 되돌리기"(한 주)로 원래대로
- **과목** (설정 탭): 과목 추가·이름 바꾸기·삭제(최대 12개), 과목마다 몬스터 타입(카드 아이콘) 선택. 이름을 바꾸면 등록된 미션도 함께 바뀜
- "하루 미션 수" 설정은 없어짐. 예전 버전을 쓰던 기기는 쓰던 자동 과목이 "매주 반복" 일정으로 옮겨져 흐름이 끊기지 않음

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체. Three.js r186이 안에 들어 있어(esbuild로 묶음, 약 800KB) **이 파일 하나로 실행됨** |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | 홈 화면 추가용 (전체 화면, 아이콘) |
| `sw.js` | 오프라인용 서비스워커. **파일을 고치면 안의 `VERSION`을 올릴 것** (안 올리면 태블릿이 옛 파일을 계속 씀) |

## 실행 방법
**PC에서 확인**: `index.html`을 더블클릭하면 크롬에서 바로 열린다 (라이브러리가 파일 안에 있어서 서버 없이 됨).
`file://`로 열면 서비스워커·홈 화면 아이콘만 동작하지 않고, 나머지(3D·미션·타이머·저장)는 전부 동작한다.

**태블릿에서 확인 (같은 와이파이)**
1. PC에서 위 서버 실행, PC의 IP 확인 (`ipconfig` → IPv4)
2. 태블릿 크롬에서 `http://PC아이피:8000/index.html`
3. 이 방식(http)에서는 서비스워커·홈 화면 아이콘이 동작하지 않음. 그건 아래 배포 후에만 됨

**배포 (GitHub Pages 예시)**
1. GitHub에 저장소를 만들고 `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`를 올린다 (`PRD-3D.md`, `README-3D.md`는 선택). git 없이 Netlify Drop(app.netlify.com/drop)에 폴더를 끌어 놓아도 된다
2. 저장소 Settings → Pages → Branch: main, 폴더: / (root) → Save
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 로 접속
4. 태블릿 크롬에서 그 주소 열기 → 메뉴(⋮) → **홈 화면에 추가** → 이후 아이콘으로 열면 주소창 없이 전체 화면, 인터넷 없어도 열림
5. 파일을 고쳐 다시 올릴 때는 `sw.js`의 `VERSION` 숫자를 올린다

## 1단계에서 구현된 것
- **크리에이터** (첫 실행 화면): 이름·타입·몸 5·눈 4·귀뿔 4·꼬리 3·색 2가지, 3D 미리보기 즉시 반영, 랜덤 조합. 이름을 넣어야 "시작" 버튼 활성화
- **홈**: 3D 몬스터 + 이름/타입 표시, 이번 주 진화 진행바(진화까지 n개 남음), 오늘 미션 카드
- **미션**: 기본 과목(수학, 수학패드, 영어 …)에서 하루 미션 수만큼 자동 생성. `시작` → 집중 모드 → `다 했어!` → 완료
- **일일 성장**: 미션 1개 완료마다 크기 +1.2% (최대 +35%) + 몸에 점무늬 1개 추가 (최대 12개). 완료 시 몬스터 2단 점프 + "+1 성장!" + 색종이(HTML)
- **주간 진행**: 월~일 완료 수 / 필요 수(하루 미션 수 × 7 × 80%). 진화 연출 자체는 4단계
- **탭 반응 제한**: 하루 30번 (`TAP_LIMIT_PER_DAY`, 미결 사항 11-1 임시값)
- **⚙ 버튼** → 부모 모드 (3단계에서 비밀번호 추가)
- **홈 화면 추가 + 오프라인**: manifest + 서비스워커

## 2단계에서 구현된 것
- **집중 모드**: 미션 카드 `시작` → 전체 화면 타이머 (미션 이름 + 큰 숫자 + 링). 기본 20분(설정 5~60분, 미션별 `minutes`는 3단계 부모 모드에서 입력)
- **3D 완전 정지**: 들어갈 때 마지막 프레임을 이미지 한 장으로 찍어 오른쪽 위 구석에 표시하고 렌더 루프를 멈춤. 나올 때 재개
- **화면 켜짐 유지**: Wake Lock API (지원 브라우저). 탭을 떠났다 오면 다시 잡음
- **시간 끝**: 링이 초록으로, `+00:00`부터 초과 시간 표시, 알람 효과음 + 진동 + 화면 깜빡임. 끝나도 강제 종료 없음 — 아이가 `다 했어!`를 눌러야 완료
- `⏸ 잠깐` (일시정지) / `← 나중에` (미션은 그대로 남고 타이머만 초기화. 벌칙 없음)
- **새로고침·재접속 복구**: 진행 중 타이머는 `state.focus`에 시작 시각으로 저장 → 다시 열어도 남은 시간이 맞음 (화면이 꺼져도 타이머는 실제 시간 기준)
- **효과음** (Web Audio, 외부 파일 없음): 탭·시작·완료·알람. 첫 터치 이후에만 소리 남. 설정에서 끌 수 있음. 무음 스위치는 웹에서 감지 못 하므로 완료·알람은 항상 진동(지원 기기)과 화면 연출을 함께 냄

## 3단계에서 구현된 것 (부모 모드, 홈의 ⚙)
- **비밀번호 6자리**: 처음 누르면 만들기(두 번 입력) → 이후 숫자 패드로 진입. 설정에서 변경. 비밀번호를 잊으면 "모든 데이터 지우기"밖에 없으니 메모해 둘 것 (해시로 저장, 보안용이 아니라 아이가 못 열게 하는 용도)
- **미션 등록** (주 단위, ◀▶로 지난주/다음 주): 요일별로 과목 추가(수학·수학패드·영어·구몬·기타, 하루 최대 5개), 분량 메모, 시간(5~60분), 삭제. 오늘 날짜는 주황 테두리
  - 등록 안 한 날은 기본 과목에서 "하루 미션 수"만큼 자동 생성
  - 오늘 계획을 바꾸면 홈의 미션 카드가 바로 바뀜. **완료한 미션은 지워지지 않음**
  - `지난주 미션 복사` / `기본 과목으로 채우기` / `이번 주 비우기`
- **달성률**: 오늘 / 이번 주 / 이번 달 (%와 개수), 최근 7일 막대, 몬스터 정보(누적 완료, 단계)
- **설정**: 하루 미션 수, 진화 기준 %(50~100), 타이머 기본값, 파츠 해금 주기(4단계에서 사용), 효과음, 3D 품질, 성능 표시, 비밀번호 변경 + 테스트·초기화(오늘 미션 재생성, 몬스터 새로, 전체 삭제)
- **데이터**: JSON 파일로 저장 / 글자로 보기(복사) / 파일 또는 붙여넣기로 가져오기(덮어쓰기 후 재시작). 기기를 옮길 때 사용
- 부모 모드가 열려 있는 동안 3D 렌더링 정지
- 주간 진화 기준(홈 진행바)은 이제 "그 주에 등록된 미션 총수 × 진화 기준 %"로 계산

## 4단계에서 구현된 것
- **단계별 모습** (`monster.stage` 0~3)
  - 0 알: 몸 색 달걀 + 포인트 색 무늬(기본 3개 + 성장 점). 눈·귀·꼬리 없음, 좌우로 흔들거림
  - 1 1차: 크리에이터에서 고른 모습, 크기 0.85
  - 2 2차: 크기 1.0, 귀·꼬리 1.25배, 장식(나비넥타이)
  - 3 최종: 크기 1.1, 날개 + 머리 위 타입 색 오라 고리(천천히 회전)
  - 크리에이터 미리보기는 1차 모습. 만들면 **알**로 시작
- **주간 진화 판정** (`checkEvolution`, 홈 진입·미션 완료 후): 만든 주부터 순서대로, 주말(토·일) 또는 지난 주에 대해 `완료 ÷ 계획(만든 날 이후)` ≥ 진화 기준이면 한 단계 진화. 미달 주는 넘어가고 다음 주에 다시 기회 (퇴화·감점 없음). 밀린 주가 여러 개면 연출이 이어서 나옴
- **진화 연출** (약 4초, `건너뛰기`): 타입 색 빛 기둥(반투명 1개, 연출 중에만) → 파티클 30개(Points 1개, 불투명) → 카메라 줌인(fov 35→27) → 플래시 → 새 모습 튀어나옴 → 줌 복귀. 연출 중 드래그 잠금. 효과음 + 진동
- **완성**: 최종 진화 시 썸네일 200×200 JPEG 캡처 → 도감 등록 → 월간 배지 화면. 완성 후에도 미션은 계속(성장만), **다음 달이 되면 홈에 "새 몬스터 만들기" 버튼**
- **파츠 해금**: 처음엔 몸 3·눈 2·귀 2·꼬리 2 (8/16). 누적 미션 `unlockEvery`(기본 7)개마다 1개씩 `UNLOCK_ORDER` 순서로 해금, 완료 연출 뒤 "🔓 새 파츠!" 표시. 잠긴 파츠는 크리에이터에서 🔒 (다음 몬스터부터 사용)
- **도감** (홈 📖): 완성 몬스터 카드(썸네일·이름·타입·완성 월·Lv), 키우는 중인 몬스터 실루엣, 다음 달 빈 칸. 카드 탭 → 최종 모습 3D로 보기(회전 가능) → `← 돌아가기`
- **부모 모드 설정 → "진화 연출 미리보기"**: 실제로 한 단계 진화시키므로 테스트용으로만

## 성능 규칙 적용 내역 (PRD 7장, 필수)
- 30fps 고정 루프, 탭이 안 보이면 렌더링 완전 정지
- 실시간 그림자 없음 → 바닥 원형 그라데이션 1장 (유일한 반투명 오브젝트)
- 조명 2개 (반구 환경광 + 주광), 후처리 없음, 툰 셰이딩용 3픽셀 그라데이션 텍스처 1장
- 픽셀 비율: 낮음 1.0 / 높음 1.5 상한, 안티앨리어싱은 높음에서만. 기본값 **낮음**
- 삼각형: 가장 무거운 조합 + 무늬 10개 + 최종 단계 장식 = 약 2,880 (예산 3,000). 성장 무늬는 6×4 구(36 삼각형)로 제한
- 진화 연출: 반투명 1개(빛 기둥)와 파티클 30개는 연출 4초 동안만 존재하고 끝나면 제거
- 완료 연출의 색종이는 3D 파티클이 아니라 HTML 요소 14개 (GPU 부담 없음)
- 왼쪽 아래 성능 표시: fps·삼각형·켜둔 시간. fps 25 미만이거나 삼각형 초과면 빨간색

## 태블릿 체크리스트 (1단계 완료 기준: 아이가 몬스터 만들고 미션 3개 완료)
- [ ] 크리에이터에서 이름 입력 시 키보드가 입력칸을 가리지 않는지
- [ ] 가로: 몬스터 왼쪽·선택지 오른쪽 / 세로: 몬스터 위·선택지 아래
- [ ] 미션 3개 완료 → 몬스터가 조금 커지고 점무늬 3개 생기는지
- [ ] 다음 날 열면 새 미션 3개가 생기고 어제 성장은 유지되는지
- [ ] 10분 켜두고 fps 30 근처 유지, 발열 확인

## 태블릿 체크리스트 (2단계 완료 기준: 타이머로 실제 숙제 1회)
- [ ] 집중 모드 동안 왼쪽 아래 성능 표시가 안 보이고(3D 정지) 태블릿이 덜 뜨거운지
- [ ] 20분 동안 화면이 꺼지지 않는지 (Wake Lock). 꺼지면 태블릿 설정의 화면 꺼짐 시간을 늘릴 것
- [ ] 시간이 끝나면 소리·진동·깜빡임이 나는지 (첫 터치 후)
- [ ] 홈 버튼으로 나갔다 돌아와도 타이머가 이어지는지

## 태블릿 체크리스트 (3단계 완료 기준: 부모가 한 주 미션 직접 등록)
- [ ] 비밀번호 만들고 다시 들어가기, 틀리면 진동
- [ ] 이번 주 미션을 요일별로 등록하고 홈에 오늘 카드가 바뀌는지
- [ ] 분량 입력 시 화면 키보드 위로 입력칸이 보이는지

## 태블릿 체크리스트 (4단계 완료 기준: 4주 완주 시나리오)
