# PRD — 몬스터 키우기 숙제 플래너 (3D 버전)

버전 0.3 · 2026-09-25 · 0~4단계 구현 반영
기반 문서: PRD.md 0.2 (2D 버전). 2D 버전은 그대로 유지하고, 이 문서는 별도 3D 버전을 위한 것.
주 사용 기기는 **태블릿**(터치, 웹호스팅으로 접속).
배포: GitHub 저장소 `3D_Scheduler_toSon`의 `monster/` 폴더 (전차 앱은 `tank/`). 변경 이력은 맨 끝 12절.

## 0. 2D 버전과 다른 점 (요약)

| 항목 | 2D 버전 | 3D 버전 |
|---|---|---|
| 기기 | PC 브라우저 | **태블릿 브라우저** (PC에서도 열림) |
| 접속 | 파일 직접 열기 | 무료 웹호스팅 주소 → 홈 화면에 아이콘으로 추가 |
| 몬스터 그래픽 | SVG 파츠 조합 | Three.js 기본 도형 조합 (로우폴리 장난감 스타일) |
| 몬스터 조작 | 정지 이미지 | 손가락 드래그로 회전, 대기 애니메이션 |
| 진화 연출 | 2D 애니메이션 | 빛 기둥·파티클·카메라 줌인 |
| UI (미션·타이머·부모 모드) | HTML | HTML 그대로 (3D 캔버스 위에 겹침) |
| 데이터 | localStorage `monsterPlanner` | localStorage `monsterPlanner3D` (완전히 별도) |
| 파일 구성 | index.html 하나 | index.html 하나 (Three.js를 파일 안에 묶어 넣음) |
| 그림 업로드 | 4단계에서 추가 | 제외 (3D 모델로 변환 불가) |

핵심 규칙(한 달 완성, 주 80% 진화, 미션 1개 = 성장 1번, 퇴화 없음)은 2D와 동일. 단, 3D 버전은 **미션을 부모가 전부 등록**한다 (4절). 부모 모드 구성은 전차 앱과 같다.

## 1. 한 줄 요약

초등 5학년, 주의가 쉽게 흐트러지는 아이가 숙제·공부 습관을 들이도록, 숙제를 완료하면 자기가 만든 3D 몬스터가 성장·진화하는 태블릿 웹앱.

## 2. 사용자

| 역할 | 설명 | 핵심 니즈 |
|---|---|---|
| 아이 (주 사용자) | 초5, 태블릿 사용(유튜브·게임 없음), 몬스터 수집물 좋아함 | 재미있고 바로 시작할 수 있을 것, 지루하지 않을 것 |
| 부모 (관리자) | 미션 등록·수정, 진행 확인 | 등록이 간단할 것, 아이 몰래 조정 가능할 것, **미션을 전부 직접 정할 수 있을 것** |

## 3. 목표와 비목표

**목표**
- 아이가 매일 스스로 앱을 열고 미션을 시작한다.
- 숙제 시작까지의 망설임을 최소화한다 (버튼 하나로 시작).
- 한 달 단위의 뚜렷한 목표(몬스터 완성)를 준다.
- 3D 몬스터로 "내 몬스터가 살아 있다"는 느낌을 강화한다.

**비목표 (이번 범위 밖)**
- 여러 아이 계정, 기기 간 진행 동기화, 앱스토어 앱
- 태블릿과 PC에서 같은 몬스터를 이어서 키우기 (아래 "기기" 규칙 참고)
- 숙제 내용 자체를 채점하거나 검사하는 기능
- 벌칙·감점·퇴화 (의도적으로 넣지 않음)
- 3D 월드 탐험, 배틀 등 게임 요소 확장 (숙제보다 게임이 커지는 것 방지)
- 외부 3D 모델 파일(glTF 등) 사용, 그림 업로드
- 2D 버전과의 데이터 연동
- **앱이 스스로 미션을 만들어 내는 것** — 미션은 부모가 등록한 것만 나온다

## 4. 핵심 규칙

| 항목 | 규칙 |
|---|---|
| 완성 주기 | 한 달 = 몬스터 1마리 완성 |
| 진화 | 주간 미션 80% 이상 달성 시 주말에 진화 (총 4단계: 알 → 1차 → 2차 → 최종) |
| 일일 성장 | 미션 1개 완료마다 몬스터가 바로 조금 자라거나 무늬가 늘어남 (하루치를 다 해야 자라는 방식 아님). 하루치를 다 하면 "오늘 미션 다 했어!" 문구 |
| 미달 주 | 진화만 다음 주로 미뤄짐. 퇴화·감점 없음 |
| 미션 등록 | **부모가 전부 등록.** "매주 반복" 요일별 일정 + 필요하면 특정 날짜만 따로 수정. 비워 둔 날은 쉬는 날 ("오늘은 쉬는 날! 🌙") |
| 하루 미션 수 | 부모가 정한 만큼 (하루 최대 5개). 고정된 "하루 미션 수" 설정은 없음 |
| 미션 시간 | 미션마다 5~60분 (5분 단위, 부모 설정), 기본 20분 |
| 과목 | 부모가 추가·이름 변경·삭제 (최대 12개). 처음 목록: 수학, 수학패드, 영어, 구몬, 기타. 분량은 미션마다 메모 |
| 타입 | 과목마다 몬스터 타입(미션 카드 아이콘)을 부모가 지정. 처음 연결: 수학=번개, 수학패드=물, 영어=불, 구몬=풀, 기타=바위 |
| 파츠 해금 | 미션 누적 7개마다 새 파츠 1개 |
| 완성 후 | 도감 등록 + 월간 배지, 새 달에 새 몬스터 제작 |
| 기기 | 아이는 태블릿 한 대만 사용. 저장이 브라우저 안에 되므로 다른 기기에서 열면 몬스터가 따로 자람. 기기를 옮길 땐 부모 모드의 내보내기/가져오기 사용 |

## 5. 3D 몬스터 설계

### 5.1 스타일
- 로우폴리·장난감 느낌 (둥글고 귀여움, 무섭지 않게)
- 부드러운 조명 + 바닥 그림자, 단색 배경 (타입 색으로 은은하게)
- 재질: 무광 파스텔 톤 (툰 셰이딩 또는 낮은 광택)

### 5.2 파츠 (기본 도형 조합)

| 파츠 | 종류 | 도형 예시 |
|---|---|---|
| 몸 | 5종 | 구, 캡슐, 납작한 구, 원기둥+반구, 물방울 |
| 눈 | 4종 | 동그란 눈, 반달 눈, 큰 눈동자, 한 눈 |
| 귀·뿔 | 4종 | 둥근 귀, 뾰족 귀, 작은 뿔 2개, 안테나 |
| 꼬리 | 3종 | 짧은 공, 지그재그, 긴 곡선 |

- 색 2가지 (몸 / 포인트)
- 파츠가 붙는 위치(앵커)를 몸 종류별로 미리 정의

### 5.3 움직임
- 대기: 위아래로 둥실, 2~4초마다 눈 깜빡임, 가끔 좌우 두리번
- 탭: 통통 튀며 반응 (하루 30회 제한 — 임시값, 무한 터치 놀이 방지)
- 드래그: 한 손가락으로 좌우 회전만 (위아래 회전·확대는 제한, 두 손가락 확대는 막음)

### 5.4 성장 표현
- 일일 성장: 크기 조금 증가 + 무늬(점·줄무늬) 추가
- 진화 단계: 알(무늬 있는 달걀) → 1차(작고 둥근 몸) → 2차(파츠 커짐 + 장식 1개) → 최종(날개·갑옷 등 장식 + 타입 오라)
- 진화 연출: 빛에 감싸짐 → 파티클 → 카메라 살짝 줌인 → 새 모습 공개 (약 4초, 건너뛰기 가능)

## 6. 화면

공통 규칙 (태블릿):
- 버튼·카드는 손가락으로 누르기 쉬운 크기 (최소 48px 이상, 간격 넉넉히)
- 가로·세로 모드 둘 다 대응. 가로에서는 몬스터 옆에 미션, 세로에서는 몬스터 아래에 미션
- 마우스 올림(hover)에 의존하는 기능 없음. 모든 정보는 화면에 보이거나 탭으로 열림
- 화면 확대·축소, 위아래 튕김(bounce) 막기
- 홈 화면 아이콘으로 열면 주소창 없이 전체 화면

### 6.1 홈 (아이)
- 중앙에 3D 몬스터
- 오늘 미션 카드 (부모가 등록한 만큼, 최대 5개) — HTML, 화면 아래쪽 → 각 카드에 "시작" 버튼 하나, 과목 타입 아이콘·분량·시간 표시
- 미션이 없을 때: 한 번도 등록하지 않았으면 "아직 미션이 없어요 — 부모님이 등록하면 여기에 나와요", 등록은 했는데 오늘이 비어 있으면 "오늘은 쉬는 날! 🌙"
- 이번 주 진행 바 (진화까지 n개 남음)
- 화면에 다른 요소 없음

### 6.2 집중 모드
- 미션 이름 + 큰 원형 타이머 (미션별 시간, 기본 20분). "잠깐"(일시정지), "나중에"(미션은 남고 타이머만 초기화, 벌칙 없음)
- **3D 렌더링 정지.** 몬스터는 정지된 작은 이미지로 한쪽 구석에만 표시 (딴짓 방지)
- 타이머 도는 동안 화면이 꺼지지 않게 (화면 켜짐 유지)
- 끝나면 "다 했어!" 버튼 → 3D 재개 + 완료 연출 (몬스터 점프 + 효과음) → 홈으로
- 효과음은 첫 화면 터치 이후에만 울림 (태블릿 브라우저 제약). 소리를 못 내거나 부모가 효과음을 끄면 진동·화면 연출로 대체

### 6.3 몬스터 크리에이터
- 3D 미리보기 (파츠 바꾸면 즉시 반영, 회전 가능) + 파츠·색·이름·타입 선택
- 가로 모드: 미리보기 왼쪽, 선택지 오른쪽 / 세로 모드: 미리보기 위, 선택지 아래
- 선택지는 큰 썸네일 버튼으로 (작은 목록 대신)
- 이름 입력 시 화면 키보드가 올라와도 입력칸이 가려지지 않게
- 첫 실행 시 이 화면이 첫 미션

### 6.4 진화·완성 연출
- 진화 조건 충족 시 홈 진입 때 전체 화면 3D 연출
- 최종 완성 시 도감 등록 + 배지 수여 화면

### 6.5 도감
- 완성 몬스터 카드 목록 (이름, 타입, 완성 월, 레벨)
- 카드 클릭 시 해당 몬스터 3D로 보기
- 미완성 칸은 실루엣
- 성능을 위해 목록에서는 썸네일 이미지(완성 시점에 캡처) 사용

### 6.6 부모 모드 (전차 앱과 같은 구성)
- 비밀번호 6자리 (화면 키패드). 처음에는 두 번 입력해서 정함. 해시로 저장
- **미션 등록**
  - [매주 반복] [날짜별] 전환. 처음 들어오면 "매주 반복"부터
  - 매주 반복: 월~일 요일별 미션 목록 → 매주 자동으로 나옴
  - 날짜별: ◀▶로 주 이동, 한 주 7일이 한 화면에. 날마다 "반복" 또는 "이 날만" 표시, 고친 날은 "반복으로" 버튼
  - 날마다 "+ 과목" 버튼으로 추가, 분량 메모, 시간 −/+ (5분 단위), 삭제. 이미 한 미션은 "완료 ✓"
  - 한 주 도구: 지난주 미션 복사, 반복 일정으로 되돌리기, 이번 주 비우기
  - 오늘 미션을 고치면 홈에 바로 반영 (완료한 항목은 유지)
- **달성률**: 오늘·이번 주·이번 달 %, 최근 7일 막대, **과목별 최근 4주**, 몬스터 정보
- **설정**: 과목 관리(이름·타입), 진화 기준 %, 타이머 기본값, 파츠 해금 주기, 효과음 켜기/끄기, **3D 품질(높음/낮음)**, 성능 표시 켜기/끄기, 비밀번호 변경
- **테스트·초기화** (설정 탭 아래): 오늘 미션 다시 만들기, 진화 연출 미리보기, 몬스터 새로 만들기, 모든 데이터 지우기
- **데이터**: 파일로 저장 / 글자로 보기(복사용) / 파일 또는 붙여넣기로 가져오기 (JSON)

## 7. 기술

**구성**
- Three.js r186을 index.html 안에 묶어 넣음 (약 800KB) → CDN 의존 없음, 파일 하나로 실행 (PC에서 더블클릭으로도 열림)
- 그 외 외부 라이브러리 없음. HTML/CSS/JS는 index.html 하나에
- 3D 캔버스는 배경 레이어, UI는 그 위 HTML 레이어
- 데이터 저장: localStorage 키 `monsterPlanner3D` — 2D 버전과 완전히 분리 (읽기·쓰기 모두 별도, 마이그레이션 없음). 3D 버전 안에서 예전 저장은 자동 변환 (예전 자동 과목은 "매주 반복" 일정으로 옮겨 흐름 유지)
- 효과음: Web Audio로 생성 (외부 파일 없음)

**배포·접속**
- GitHub Pages: `https://lprince98.github.io/3D_Scheduler_toSon/monster/` (첫 화면 `…/3D_Scheduler_toSon/`에서 몬스터·전차 선택)
- 홈 화면 추가 시 앱처럼 보이도록 manifest + 아이콘 + 전체 화면 설정. manifest scope는 `monster/` 폴더라 전차와 따로 설치됨
- 서비스워커로 오프라인에서도 열리게 (인터넷 끊겨도 숙제는 해야 하므로). 캐시 이름은 `monster3d-` 접두어, 같은 주소의 전차 캐시는 지우지 않음. 파일을 고치면 `sw.js`의 `VERSION`을 올릴 것
- 부모가 주소를 타블렛에 한 번만 입력하면 되도록 README에 배포 절차 기록

**대상 기기 (성능 기준선)**
- 네오탭 Z11 Plus — 11인치 FHD, Helio G99 (Mali-G57 급 GPU), RAM 8GB, 안드로이드, 배터리 8000mAh
- 보급형 태블릿이므로 3D는 처음부터 가볍게 설계한다. 아래 성능 항목은 권장이 아니라 **필수 조건**으로 취급
- 브라우저는 안드로이드 크롬 기준

**화면**
- 11인치 FHD (1920×1200) 기준, 가로·세로 모두 대응, PC에서도 깨지지 않게
- 뷰포트 설정으로 확대 금지, 안전영역(노치·홈 인디케이터) 여백 반영
- 회전하거나 키보드가 올라올 때 캔버스 크기 자동 조정

**입력**
- 포인터 이벤트로 터치·마우스 동시 지원
- 펜은 정전식(디스크팁 2mm, 필압·팜리젝션 없음)이라 손가락 입력과 구분되지 않음 → 펜 전용 처리 없음. 버튼 크기는 손가락 기준을 유지
- 3D 캔버스 위에서만 드래그 제스처 처리, 나머지 화면은 평범하게 스크롤
- 길게 누르기로 뜨는 선택/확대 메뉴 막기

**성능 (보급형 태블릿 기준, 필수)**
- 목표 30fps 안정 (60fps는 욕심내지 않음). 아이는 끊김보다 발열·배터리에 더 영향받음
- 실시간 그림자 사용 안 함 → 몬스터 아래에 단순한 원형 그림자 이미지 한 장
- 폴리곤 예산: 몬스터 1마리 약 3,000 삼각형 이하, 화면에 몬스터는 1마리만
- 파티클은 30개 이하, 진화 연출 동안만. 반투명 효과 최소화 (보급형 GPU가 가장 약한 부분)
- 픽셀 비율 상한 1.5, 안티앨리어싱은 켜보고 느리면 끔
- 후처리 효과(블룸 등) 사용 안 함. 빛 번짐은 간단한 이미지로 흉내
- 조명은 2개 이하 (주광 + 환경광)
- 화면이 안 보이거나 집중 모드일 때 렌더링 완전 정지 (배터리·발열)
- 품질 설정 기본값 **낮음**, 부모 모드에서 높음으로 변경 가능
- 0단계에서 실기기로 10분 이상 켜두고 발열·프레임 확인. 여기서 미달이면 3D를 접고 2D 버전으로 돌아간다

## 8. 개발 단계

| 단계 | 내용 | 완료 기준 | 상태 |
|---|---|---|---|
| 0 | 3D 몬스터 프로토타입: 파츠 조합 + 대기 동작 + 터치 회전 | 태블릿 실기기에서 부드럽게 돌아가고, 아이가 보고 "귀엽다"고 함 | 구현 완료 |
| 1 | 크리에이터 + 홈 + 미션 완료 + 일일 성장 | 아이가 태블릿에서 몬스터 만들고 미션 3개 완료해봄 | 구현 완료 |
| 2 | 집중 모드 타이머 + 3D 정지/재개 + 완료 연출·효과음 | 타이머로 실제 숙제 1회 | 구현 완료 |
| 3 | 부모 모드 (등록·설정·달성률) | 부모가 한 주 미션 직접 등록 | 구현 완료 (0.3에서 매주 반복·과목 관리·과목별 달성률 추가) |
| 4 | 주간 진화 3D 연출 + 파츠 해금 + 도감 + 배지 | 4주 완주 시나리오 동작 | 구현 완료 |

0단계가 추가된 이유: 3D는 스타일이 마음에 안 들면 뒤에서 고치기 어렵고, 태블릿 성능도 여기서 확인해야 하므로 몬스터 모습부터 먼저 만든다. 0단계부터 태블릿 실기기로 확인한다 (PC 브라우저만 보고 넘어가지 않는다).

## 9. 성공 지표 (한 달 후)

- 주 5일 이상 아이가 스스로 앱을 연다
- 주간 달성률 평균 70% 이상
- 아이가 "다음 몬스터 뭐 만들지" 이야기한다
- (2D와 비교) 아이가 어느 버전을 더 자주 여는지
- 태블릿 홈 화면 아이콘으로 바로 연다 (주소를 찾아 헤매지 않는다)

## 10. 확정 사항

1. 핵심 규칙은 2D 버전과 동일
2. 몬스터만 3D, UI는 HTML
3. 집중 모드에서는 3D 정지
4. 데이터는 2D 버전과 별도 저장 (연동 없음)
5. 그림 업로드는 3D 버전에서 제외
6. 주 사용 기기는 태블릿 한 대(네오탭 Z11 Plus), 무료 웹호스팅 주소로 접속
7. 3D 품질 기본값은 낮음, 목표 30fps
8. 펜(로랜텍 초미세 터치펜)은 손가락과 동일하게 처리. 펜 전용 기능·그리기 기능 없음
9. 미션 1개 완료 = 성장 1번 즉시 (하루치 묶음 보상 아님)
10. 미션은 부모가 전부 등록 (매주 반복 + 날짜별 수정). 앱이 자동으로 만드는 기본 미션 없음
11. 부모 모드는 전차 앱과 같은 구성
12. GitHub Pages 저장소 하나에 `monster/`, `tank/` 폴더로 나눠 배포

## 11. 미결 사항

1. 몬스터 탭 반응 횟수 제한 — 지금은 하루 30회 임시값. 실제 사용 후 조정
