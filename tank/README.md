# 전차 조립 숙제 플래너 — 3D 태블릿 웹앱

PRD: `PRD-TANK.md` · 현재 단계: **4단계 (주간 해금 · 도색·마킹 · 완성 연출 · 제원 카드 · 차고 목록)** — 4주 완주 시나리오 동작

## 부모 모드 — 몬스터 앱과 같은 구성 (v4.2)

- **미션 등록**: [매주 반복] [날짜별] 전환. 날짜별은 ◀▶로 아무 주나 이동, 한 주 7일이 한 화면에 세로로 나옴. 날마다 "+ 과목" 버튼으로 추가, 분량 메모, 시간 −/+ 5분 단위(5~60분), 이미 한 미션은 "완료 ✓". 고친 날은 "이 날만" + "반복으로" 버튼. 한 주 도구: 지난주 미션 복사 / 반복 일정으로 되돌리기 / 이번 주 비우기
- **달성률**: 오늘·이번 주·이번 달, 최근 7일 막대, 과목별 최근 4주(연결된 전차 부위와 회색 부품 수), 전차 정보
- **설정**: 과목 관리, 단계 해금 기준(50~100%), 타이머 기본값(5~60분), 효과음 켜기/끄기(끄면 진동만), 3D 품질, 성능 표시(HUD) 켜기/끄기, 비밀번호 변경. 아래에 테스트·초기화(오늘 미션 다시 만들기, 다음 단계, 부품 전부 결합, 모든 데이터 지우기)
- **데이터**: 파일로 저장 / 글자로 보기(복사용) / 파일 또는 붙여넣기로 가져오기
- 비밀번호는 해시로 저장 (예전 평문 비밀번호는 자동 변환, 같은 번호로 계속 열림)
- 집중 모드의 시간 선택지에 부모가 정한 시간(예: 25분)도 함께 나옴

## 미션은 부모가 전부 등록 (v4.1)

- 앱이 스스로 만드는 미션은 없습니다. 처음 설치하면 차고에 "아직 미션이 없어요 — 부모님이 등록하면 여기에 나와요"가 뜨고, 부모 모드는 "매주 반복" 화면으로 열립니다
- **매주 반복**: 요일별 미션 목록(과목·분량 메모·시간, 하루 최대 5개). 매주 자동으로 반복됩니다. 비워 둔 요일은 쉬는 날
- **날짜별**: 특정 날짜만 바꿀 때 씁니다 (v4.2 화면은 위 참고). 반복 일정 자체는 바뀌지 않습니다
- **과목 관리** (설정 탭): 과목 추가·이름 바꾸기·삭제(최대 12개), 과목마다 연결할 전차 모듈 선택. 이름을 바꾸면 등록된 미션도 함께 바뀌고, 지운 과목의 기존 미션은 그대로 남습니다(모듈은 승무원 장비로 처리)
- 오늘 미션을 고치면 차고에 바로 반영됩니다. 이미 시작했거나 완료한 항목은 그대로 둡니다
- 예전 "하루 미션 수" 설정은 없어졌습니다. 기존 저장(`version: 3`)은 쓰던 자동 과목이 "매주 반복" 일정으로 옮겨져서 흐름이 끊기지 않습니다(`version: 4`)

## 4단계에서 동작하는 것

- **주간 해금**: `build.stage` 1~4(하부→상부→무장·장비→마감). 부품은 현재 단계 것만 붙고, 단계 부품이 다 붙으면 미션 완료 시 회색 부품 교체만 함. 토요일부터 그 주 달성률(완료/계획)이 설정 기준(기본 80%) 이상이면 다음 단계로. 판정은 주마다 한 번(`build.evaluated`), 앱을 열 때 지난 주들을 몰아서 판정. 미달이면 그대로(부품 회수 없음)
- **4주차 마감**: 미션 1개 완료 = 꾸미기 항목 1개 해금 (기본 도색 → 위장 무늬 → 마킹 → 완성 검수). 4주차 달성률 통과 → 완성
- **꾸미기** (차고 "꾸미기" 버튼): 기본색 4종(독일 황색·회색, 소련 녹색, 미국 올리브 — 국가 기본색 표시), 위장 4종(단색·삼색·겨울 백색·디지털; 256px 캔버스 텍스처를 도색 재질에 입힘), 마킹(국적 마크·부대 마크 3종·차체 번호 3자리 — OS 키보드 대신 화면 키패드). 마킹은 포탑·차체 쉬르첸 위 데칼 평면(각 4삼각형). 회색 임시 부품에는 도색이 적용되지 않음
- **완성 연출**: 차고 진입 때 `build.status === 'ceremony'`면 전체 화면 → "완성!" 1.6초(자동 회전) → 시운전 5초(앞으로 2.5초·뒤로 2.5초 주행, 바퀴 회전, 포탑 좌우 선회, 사격 없음, 건너뛰기 가능) → 제원 카드(국가·연도·주포·중량·최고속도·승무원·생산) + 월간 완성 배지 → "차고에 등록"
- 등록 시: 남은 부품이 있으면 정품으로 자동 결합(완성 검수), 320×200 썸네일 캡처, `garage[]`에 저장(전차·완성 월·도색·회색 부품 수), 다음 등급 해금 안내 → 전차 선택 화면으로
- **등급 트리**: 초급 1대 완성 → 중급(티거 I·IS-2·M26) 해금, 중급 1대 → 현대(레오파르트 2·T-90·K2·M1). 모델은 4호 전차만 있어서 나머지는 "모델 준비 중"(5단계)
- **차고 목록** ("차고 목록" 버튼): 완성한 전차 카드(썸네일·이름·국가·완성 월·도색) + 등급별 목록(미완성·잠김은 실루엣). 완성 카드를 누르면 3D로 보기 + 도색 변경(꾸미기 화면 재사용, 변경 시 썸네일 재캡처). 보기 중 현재 조립 상태는 백업했다가 복원
- **테스트 버튼** (부모 모드 > 데이터): "이번 주 달성 처리 → 다음 단계"(4주차에서 누르면 완성), "현재 단계 부품 전부 결합". 4주를 기다리지 않고 완주 시나리오를 확인할 때
- 저장 구조 `version: 3` (`build`, `decor`, `garage` 추가). 이전 버전은 자동 변환

## 3단계에서 동작하는 것

- 차고 아래 "부모" 버튼 → 6자리 숫자 키패드. 처음엔 비밀번호를 정함(두 번 입력). 저장은 `settings.pin` (평문 — 아이 몰래 조정용이지 보안용이 아님)
- **미션 등록**: v4.1에서 "매주 반복 + 주별 수정" 방식으로 바뀜 (위 참고). "지난 주 복사"는 지난 주에 따로 고친 요일을 가져옴
- **달성률**: 오늘/이번 주/이번 달 %, 모듈별(과목별) 최근 4주 완료율 + 회색 임시 부품 수, 최근 2주 일별 막대
- **설정**: 과목 관리(v4.1), 해금 기준(60~100%), 타이머 기본값, 3D 품질(낮음=픽셀비율 1.0·AA 끔 / 높음=1.5·AA 켬, 기본 낮음), 비밀번호 변경
- **데이터**: JSON 내보내기(`tankPlanner-YYYY-MM-DD.json`, 안드로이드는 다운로드 폴더) / 가져오기(덮어쓰기) / 전체 초기화(비밀번호는 유지)
- 저장 구조 `version: 2` — 1단계 저장(`version: 1`)은 자동 변환. 지난 날 미션은 `history`, 등록한 주간 미션은 `plan`(월요일 날짜 키)
- 3D 렌더링은 차고·전차 선택 화면에서만 돌고, 집중 모드·부모 모드에서는 정지(HUD `3D 정지`)

## 2단계에서 동작하는 것

- 미션 카드 "시작" → **집중 모드**: 먼저 시간을 고른다(20·30·40·50분, `DURATIONS`) → "시작"을 눌러야 타이머가 돈다. 미션 이름 + 큰 타이머. 3D 캔버스는 `display:none` + 렌더 루프 정지 (HUD에 `3D 정지`). 전차는 정지 직전 프레임을 JPEG로 찍어 오른쪽 아래 작은 이미지로만 표시
- 타이머는 `startedAt` 기준으로 계산 → 앱을 닫았다 열어도 이어짐. 카드 버튼이 "이어서"로 바뀜
- 시간이 끝나면 초록색 `+MM:SS` 초과 표시 + 종료 차임 + 진동 (한 번만)
- 화면 꺼짐 방지: Screen Wake Lock API. 탭을 다시 보면 자동 재요청. **https에서만 동작** (로컬 http에서는 콘솔에 `wakeLock 실패` 경고, 타이머는 정상)
- "완료" → 3D 재개 → 차고 → 0.35초 뒤 부품이 날아와 결합. 도착 순간 금속 충돌음 + 화면 번쩍임 + 진동. 회색 임시 부품은 둔탁한 소리
- "나가기" → 진행 중 상태 그대로 차고로 (타이머는 계속 감)
- 효과음은 Web Audio로 합성 (외부 파일 없음). 브라우저 정책상 **첫 터치 이후**에만 AudioContext가 켜짐. 소리를 못 내는 상태(첫 터치 전, AudioContext 실패)면 진동만. 기기 무음 스위치는 웹에서 감지 불가 → 진동은 항상 같이 울리고, 화면 번쩍임은 항상 나옴

## 1단계에서 동작하는 것

- 전차 선택 화면: 초급 3종 카드. 지금은 4호 전차만 실제 모델, T-34·M4는 "모델 준비 중"
- 차고(홈): 3D 전차(좌우 회전) + 오늘 미션 3개 카드 + 이번 주 진행 바
- 미션 완료 → 부품 1개가 날아와 결합
- 부품 44개 (하부 16 / 상부 14 / 무장·장비 14). 목록과 순서는 `index.html`의 `PZ4_PARTS`
- 과목 ↔ 모듈: 수학=주포·조준, 수학패드=엔진·변속기, 영어=무전기·통신, 구몬=장갑·궤도, 기타=승무원 장비
- 모듈이 안 맞는 부품은 **회색 임시 부품**으로 붙고, 나중에 그 과목을 하면 제색으로 교체됨
- 저장: `localStorage["tankPlanner"]` (전차, 붙은 부품, 오늘 미션, 주간 완료 수). 몬스터 버전과 별도
- 오늘 미션은 부모가 등록한 것만 (v4.1)

## 1. 개발 중 확인 — PC에서 로컬 서버 띄우고 태블릿으로 접속

`index.html`을 더블클릭으로 열면 **안 됩니다** (ES 모듈은 `file://`에서 차단됨). 반드시 서버로 띄웁니다.

### 1-1. 서버 실행 (Windows PC, 이 폴더에서)

```powershell
cd D:\workspace\work_claude_code\cho5_schedule_monster\3D_Scheduler_toSon\tank
python -m http.server 8000
```

Node가 편하면 `npx serve -l 8000 .` 도 됩니다. 실행 중인 터미널 창을 닫으면 서버가 꺼집니다.

### 1-2. PC 주소 확인

```powershell
ipconfig
```

`무선 LAN 어댑터 Wi-Fi` 항목의 **IPv4 주소** (예: `192.168.0.23`).

### 1-3. 태블릿에서 열기

1. 태블릿과 PC를 **같은 Wi-Fi**에 연결
2. 안드로이드 크롬 주소창에 `http://192.168.0.23:8000` 입력 (PC 주소로 바꿔서)
3. 왼쪽 위 HUD에서 `tris` / `fps` 확인. 화면을 손가락으로 좌우 드래그

접속이 안 되면:
- Windows 방화벽이 8000 포트를 막고 있을 수 있음 → 처음 서버 실행 시 뜨는 "액세스 허용" 창에서 **개인 네트워크** 체크. 놓쳤으면 `Windows Defender 방화벽 > 고급 설정 > 인바운드 규칙 > 새 규칙 > 포트 8000 TCP 허용`
- 공유기의 "AP 격리(무선 단말 간 통신 차단)"가 켜져 있으면 안 됨 → 공유기 설정에서 끔
- 서버 터미널에 `GET /index.html` 로그가 찍히는지 확인

### 1-4. 로컬 서버(http)에서 되는 것 / 안 되는 것

| 항목 | 로컬 `http://192.168.x.x` | 배포 후 `https://` |
|---|---|---|
| 3D 렌더·터치 회전·fps 확인 | 됨 | 됨 |
| 서비스워커 (오프라인) | **안 됨** — 브라우저가 https 아니면 등록 거부 (콘솔에 경고만, 앱은 정상) | 됨 |
| 홈 화면 추가 → 전체 화면 앱처럼 열기 | 바로가기만 생김 (주소창 보임) | 됨 |

0단계 검증(실루엣 알아보기, 30fps, 10분 발열)은 로컬 서버로 충분합니다. 홈 화면 앱·오프라인은 배포 후에 확인합니다.

### 1-5. PC에서 태블릿 크롬 디버깅 (fps 정밀 측정, 콘솔 보기)

1. 태블릿: 설정 > 휴대전화 정보 > 빌드 번호 7번 탭 → 개발자 옵션 > **USB 디버깅** 켬
2. USB로 PC 연결, PC 크롬에서 `chrome://inspect` → 태블릿의 탭 옆 **inspect**
3. DevTools > Performance 탭에서 기록하면 프레임별 시간이 보임

## 2. 배포 — 태블릿에 주소 한 번만 넣으면 되게

정적 파일뿐이라 무료 호스팅이면 어디든 됩니다. 두 가지 중 하나를 고르세요.

### 방법 A. Netlify Drop (가장 빠름, 계정 없이 가능)

1. https://app.netlify.com/drop 접속
2. 이 폴더(`3d_tankmaker`) 전체를 브라우저 창으로 **드래그 앤 드롭**
3. 몇 초 뒤 `https://xxxx-yyyy.netlify.app` 주소가 생김 → 이게 태블릿에 넣을 주소
4. 파일을 고친 뒤에는 같은 페이지에 다시 드롭하면 새 주소가 나옴. **주소를 고정하려면** 무료 계정 가입 후 사이트 이름을 정하면 됨 (Site settings > Change site name)

> 계정 가입 후에는 사이트 페이지 > Deploys 탭에 폴더를 드롭하면 같은 주소로 갱신됩니다.

### 방법 B. GitHub Pages (git으로 관리하고 싶을 때)

1. GitHub에 저장소 만들기 (예: `tank-planner`, Public)
2. 이 폴더에서:
   ```powershell
   git init
   git add .
   git commit -m "0단계: 4호 전차 프로토타입"
   git branch -M main
   git remote add origin https://github.com/<계정>/tank-planner.git
   git push -u origin main
   ```
3. 저장소 **Settings > Pages > Build and deployment > Source: Deploy from a branch**, Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<계정>.github.io/tank-planner/` 에서 열림
5. 이후 수정은 `git add . && git commit -m "..." && git push` 만 하면 자동 반영

### 배포 후 태블릿 설정 (한 번만)

1. 안드로이드 크롬으로 배포 주소 접속
2. 오른쪽 위 `⋮` 메뉴 > **홈 화면에 추가** (또는 "앱 설치") → 이름 확인 → 추가
3. 홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 열림
4. 한 번 연 뒤에는 Wi-Fi가 없어도 열림 (서비스워커 캐시)

### 파일을 고친 뒤 태블릿에 반영하기

서비스워커가 옛 파일을 캐시하고 있으므로, 파일을 수정했으면 **반드시 `sw.js`의 `VERSION` 값을 올린 뒤** 배포합니다 (예: `tank-v2.0.0` → `tank-v2.0.1`). 태블릿에서 앱을 완전히 닫았다가 두 번 열면 새 버전이 적용됩니다.

그래도 옛 화면이 보이면: 크롬 > 설정 > 사이트 설정 > 저장용량 > 해당 주소 > 삭제, 또는 홈 화면 아이콘을 지우고 다시 추가.
