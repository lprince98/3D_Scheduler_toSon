# PRD — 전차 조립 숙제 플래너 (3D, 태블릿)

버전 0.1 · 2026-09-22 · 검토용
기반 문서: PRD-3D.md 0.2 (몬스터 3D 버전). 몬스터 버전과 규칙 구조는 같고, 소재만 전차로 바꾼 별도 앱.

## 0. 몬스터 3D 버전과 다른 점

| 항목 | 몬스터 버전 | 전차 버전 |
|---|---|---|
| 소재 | 오리지널 몬스터 | 실존 전차 (단순화한 로우폴리) |
| 제작 | 파츠 조합으로 새 생명체 만들기 | 실존 전차 1대를 골라 조립해 완성 |
| 일일 성장 | 크기·무늬가 조금씩 변함 | 부품 1개가 실제로 붙음 |
| 주간 진화 | 형태가 진화 | 조립 단계 해금 (하부 → 상부 → 무장 → 마감) |
| 과목 연결 | 속성 타입 | 전차 모듈 (주포·엔진·무전기·장갑) |
| 도감 | 몬스터 도감 | 차고 (완성한 전차 부대) |
| 장기 동기 | 새 몬스터 제작 | 등급 트리 해금 (초급 → 중급 → 현대전차) |
| 데이터 | `monsterPlanner3D` | `tankPlanner` (완전히 별도) |

핵심 규칙(한 달 완성, 주 80% 달성 시 다음 단계, 하루 3개, 퇴화 없음)은 동일.

## 1. 한 줄 요약

전차를 좋아하는 초등 5학년이 숙제·공부 습관을 들이도록, 숙제를 완료할 때마다 부품이 하나씩 붙어 한 달에 실존 전차 1대를 완성하는 태블릿 웹앱.

## 2. 사용자

| 역할 | 설명 | 핵심 니즈 |
|---|---|---|
| 아이 (주 사용자) | 초5, 태블릿 사용, 전차 지식이 많고 월드 오브 탱크를 즐김 | 전차가 그럴듯할 것, 바로 시작할 수 있을 것 |
| 부모 (관리자) | 주간 숙제 등록, 진행 확인 | 등록이 간단할 것, 아이 몰래 조정 가능할 것 |

아이가 전차를 잘 안다는 점이 이 앱의 가장 큰 기회이자 위험이다. 실루엣이 어설프면 바로 알아채고 흥미를 잃는다.

## 3. 목표와 비목표

**목표**
- 아이가 매일 스스로 앱을 열고 미션을 시작한다.
- 숙제 시작까지의 망설임을 최소화한다 (버튼 하나로 시작).
- 한 달 단위의 뚜렷한 목표(전차 1대 완성)를 준다.
- 완성한 전차가 차고에 쌓이며 수집 동기를 만든다.

**비목표 (이번 범위 밖)**
- **전투·사격·적 등장.** 조립·도색·시운전까지만. 전투가 들어가면 숙제 앱이 아니라 게임이 되고, 아이가 숙제보다 게임을 하러 온다
- 월드 오브 탱크를 비롯한 게임의 모델·로고·UI·용어 화면을 그대로 가져오는 것 (실존 전차를 직접 단순화해 만든다)
- 외부 3D 모델 파일(glTF 등) 사용 — 라이선스·용량 문제. 기본 도형으로 직접 조립
- 여러 아이 계정, 기기 간 진행 동기화, 앱스토어 앱
- 숙제 내용 자체를 채점하거나 검사하는 기능
- 벌칙·감점·부품 회수 (의도적으로 넣지 않음)

## 4. 핵심 규칙

| 항목 | 규칙 |
|---|---|
| 완성 주기 | 한 달 = 전차 1대 완성 |
| 조립 단계 | 주간 미션 80% 이상 달성 시 주말에 다음 단계 해금 (4단계: 하부 → 상부 → 무장·장비 → 마감) |
| 일일 성장 | 미션 1개 완료 = 부품 1개가 전차에 붙음 (화면에서 바로 보임) |
| 미달 주 | 다음 단계만 미뤄짐. 이미 붙은 부품은 사라지지 않음 |
| 미션 단위 | 20분 이내로 쪼갠 숙제 |
| 하루 미션 수 | 기본 3개, 부모가 1~5개로 조정 |
| 기본 과목 | 수학, 수학패드, 영어, 구몬 (과목명만, 분량은 부모 모드에서 선택 입력) |
| 과목 = 모듈 | 수학=주포·조준장치, 수학패드=엔진·변속기, 영어=무전기·통신, 구몬=장갑·궤도, 기타=승무원 장비·부속 |
| 미완 모듈 | 해당 과목을 빼먹으면 그 부위가 회색 임시 부품으로 붙음. 나중에 그 과목을 하면 제대로 된 부품으로 교체 |
| 해금 | 전차 1대 완성마다 다음 등급 전차 해금 |
| 기기 | 아이는 태블릿 한 대만 사용. 저장이 브라우저 안에 되므로 다른 기기에서 열면 진행이 따로 감. 기기를 옮길 땐 부모 모드의 내보내기/가져오기 사용 |

## 5. 전차 설계

### 5.1 수록 전차 (등급 트리)

| 등급 | 전차 | 해금 조건 |
|---|---|---|
| 초급 | 4호 전차 (독일), T-34 (소련), M4 셔먼 (미국) | 처음부터 선택 가능 |
| 중급 | 티거 I (독일), IS-2 (소련), M26 퍼싱 (미국) | 초급 1대 완성 |
| 현대 | 레오파르트 2 (독일), T-90 (러시아), K2 흑표 (한국), M1 에이브람스 (미국) | 중급 1대 완성 |

- 한 달에 1대씩 고른다. 같은 전차를 다시 만들 수도 있다 (도색·마킹을 달리해서)
- 전차마다 부품 수는 비슷하게 맞춘다 (한 달 = 미션 약 60개 기준)
- 1차 개발은 초급 3종만. 나머지는 완성 후 추가

### 5.2 조립 단계 (4주)

| 주 | 단계 | 붙는 부품 |
|---|---|---|
| 1주 | 하부 | 차대, 보기륜, 유동륜·기동륜, 궤도 |
| 2주 | 상부 | 차체 상부, 포탑, 큐폴라, 해치 |
| 3주 | 무장·장비 | 주포, 포방패, 기관총, 안테나, 공구함, 예비 궤도, 연료통 |
| 4주 | 마감 | 도색, 위장 무늬, 부대 마크, 차체 번호 → 완성 검수 |

- 부품이 붙을 때 짧은 조립 효과 (부품이 제자리로 날아와 결합 + 소리)
- 각 부품은 어느 모듈(과목)에 속하는지 표시

### 5.3 꾸미기 (4주차 + 완성 후 언제든)
- 기본 도색: 국가별 기본색 (독일 회색·황색, 소련 녹색, 미국 올리브)
- 위장 무늬: 단색, 삼색 위장, 겨울 백색, 디지털 위장
- 마킹: 국적 마크, 부대 마크, 차체 번호 (아이가 숫자 직접 입력)
- 부속품 위치: 공구함·예비 궤도를 차체 어디에 붙일지 선택
- 완성한 전차도 차고에서 다시 도색·마킹 변경 가능

### 5.4 완성 보상
- 시운전: 포탑이 좌우로 돌고 전차가 짧게 주행 (약 5초, 건너뛰기 가능). 사격 없음
- 제원 카드: 그 전차의 실제 정보 한 장 (국가, 연도, 주포 구경, 중량, 최고 속도, 승무원 수)
- 차고 등록 + 월간 완성 배지
- 다음 등급 해금 안내

### 5.5 그래픽 원칙
- 실루엣 우선. 디테일보다 **차체 비율, 포탑 형상, 보기륜 개수**를 맞춘다 (아이가 알아보는 근거)
- 로우폴리·모형 장난감 느낌. 사실적 질감 대신 깔끔한 단색 + 약간의 음영
- 궤도는 개별 링크를 만들지 않고 이어진 띠 + 반복 무늬로 표현
- 배경은 단순한 차고 바닥과 벽 (소품 최소)

## 6. 화면

공통 규칙 (태블릿):
- 버튼·카드는 손가락으로 누르기 쉬운 크기 (최소 48px 이상, 간격 넉넉히)
- 가로·세로 모드 둘 다 대응. 가로에서는 전차 옆에 미션, 세로에서는 전차 아래에 미션
- 마우스 올림(hover)에 의존하는 기능 없음
- 화면 확대·축소, 위아래 튕김 막기
- 홈 화면 아이콘으로 열면 주소창 없이 전체 화면

### 6.1 차고 (홈)
- 중앙에 조립 중인 전차 (3D, 손가락으로 좌우 회전)
- 오늘 미션 카드 (기본 3개, 최대 5개) → 각 카드에 "시작" 버튼 하나. 카드에 어느 모듈인지 아이콘 표시
- 이번 주 진행 바 (다음 단계까지 n개 남음)
- 화면에 다른 요소 없음

### 6.2 집중 모드
- 미션 이름 + 큰 타이머 (기본 20분, 미션별 설정)
- **3D 렌더링 정지.** 전차는 정지된 작은 이미지로 한쪽 구석에만 표시
- 타이머 도는 동안 화면이 꺼지지 않게
- 끝나면 "완료" 버튼 → 3D 재개 + 부품 결합 연출 + 효과음 → 차고로
- 효과음은 첫 화면 터치 이후에만 울림. 무음 상태면 진동·화면 연출로 대체

### 6.3 전차 선택 (월초)
- 이번 달에 만들 전차 고르기. 해금된 전차만 선택 가능, 잠긴 전차는 실루엣
- 각 전차의 간단한 소개 한 줄 (국가, 연도, 별명)
- 가로: 목록 왼쪽·미리보기 오른쪽 / 세로: 미리보기 위·목록 아래

### 6.4 도색·꾸미기
- 3D 미리보기 + 색·무늬·마킹 선택
- 선택지는 큰 썸네일 버튼
- 차체 번호 입력 시 화면 키보드에 가려지지 않게

### 6.5 완성 연출
- 4주차 조건 충족 시 차고 진입 때 전체 화면 연출 → 시운전 → 제원 카드 → 차고 등록

### 6.6 차고 목록 (도감)
- 완성한 전차 카드 목록 (이름, 국가, 완성 월, 도색)
- 카드를 누르면 3D로 보기 + 도색 변경
- 미완성(미해금) 칸은 실루엣
- 성능을 위해 목록은 썸네일 이미지(완성 시점에 캡처) 사용

### 6.7 부모 모드
- 비밀번호(6자리)로 진입
- 이번 주 미션 등록 (요일별, 과목, 예상 시간), 지난 미션 복사
- 달성률 (일/주/월), 모듈별 균형 확인 (어느 과목이 밀리는지)
- 설정: 하루 미션 수, 단계 해금 기준 %, 타이머 기본값, 3D 품질(높음/낮음)
- 데이터 내보내기/가져오기 (JSON)

## 7. 기술

**구성**
- Three.js (ES 모듈). 라이브러리 파일을 같은 폴더에 두고 불러옴 → CDN 의존 없음
- 그 외 외부 라이브러리 없음. HTML/CSS/JS는 index.html 하나에
- 전차는 기본 도형(상자, 원기둥, 사다리꼴)을 코드로 조합. 외부 모델 파일 없음
- 3D 캔버스는 배경 레이어, UI는 그 위 HTML 레이어
- 데이터 저장: localStorage 키 `tankPlanner` — 몬스터 버전과 완전히 분리
- 효과음: Web Audio로 생성 (외부 파일 없음)

**배포·접속**
- 무료 정적 웹호스팅(Netlify, GitHub Pages 등)에 올리고, 태블릿에서 그 주소로 접속
- 홈 화면 추가 시 앱처럼 보이도록 manifest + 아이콘 + 전체 화면 설정
- 서비스워커로 오프라인에서도 열리게
- 부모가 주소를 태블릿에 한 번만 입력하면 되도록 README에 배포 절차 기록

**대상 기기 (성능 기준선)**
- 네오탭 Z11 Plus — 11인치 FHD, Helio G99 (Mali-G57 급 GPU), RAM 8GB, 안드로이드
- 보급형이므로 아래 성능 항목은 권장이 아니라 **필수 조건**
- 브라우저는 안드로이드 크롬 기준

**화면**
- 11인치 FHD (1920×1200) 기준, 가로·세로 모두 대응, PC에서도 깨지지 않게
- 뷰포트 설정으로 확대 금지, 안전영역 여백 반영
- 회전하거나 키보드가 올라올 때 캔버스 크기 자동 조정

**입력**
- 포인터 이벤트로 터치·마우스 동시 지원
- 펜(로랜텍 초미세 터치펜)은 정전식이라 손가락과 구분되지 않음 → 펜 전용 처리 없음. 버튼 크기는 손가락 기준 유지
- 3D 캔버스 위에서만 드래그 회전 처리, 나머지 화면은 평범하게 스크롤
- 길게 누르기로 뜨는 선택/확대 메뉴 막기

**성능 (필수)**
- 목표 30fps 안정
- 폴리곤 예산: 전차 1대 약 4,000 삼각형 이하. 화면에 전차는 1대만
- 보기륜은 같은 형태를 반복 배치 (인스턴싱), 궤도는 개별 링크 만들지 않음
- 실시간 그림자 사용 안 함 → 전차 아래 단순한 그림자 이미지 한 장
- 조명 2개 이하, 후처리 효과 없음, 반투명 최소화
- 픽셀 비율 상한 1.5, 안티앨리어싱은 느리면 끔
- 화면이 안 보이거나 집중 모드일 때 렌더링 완전 정지
- 품질 설정 기본값 **낮음**, 부모 모드에서 변경 가능
- 0단계에서 실기기로 10분 이상 켜두고 발열·프레임 확인

## 8. 개발 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 0 | 전차 1종(4호 전차) 3D 프로토타입 + 터치 회전 | **아이에게 보여줬을 때 무슨 전차인지 맞힌다.** 태블릿에서 30fps 유지 |
| 1 | 전차 선택 + 차고(홈) + 미션 완료 + 부품 결합 | 아이가 전차 고르고 미션 3개 완료해 부품 3개 붙임 |
| 2 | 집중 모드 타이머 + 3D 정지/재개 + 결합 연출·효과음 | 타이머로 실제 숙제 1회 |
| 3 | 부모 모드 (등록·설정·달성률) | 부모가 한 주 미션 직접 등록 |
| 4 | 주간 단계 해금 + 도색·마킹 + 완성 연출 + 차고 + 제원 카드 | 4주 완주 시나리오 동작 |
| 5 | 중급·현대 전차 추가 | 해금 흐름 동작 |

0단계 검증이 가장 중요하다. 아이가 전차를 알아보지 못하면 뒤 단계를 만들어도 소용없다. 여기서 실루엣을 고치거나, 안 되면 계획을 접는다.

## 9. 성공 지표 (한 달 후)

- 주 5일 이상 아이가 스스로 앱을 연다
- 주간 달성률 평균 70% 이상
- 아이가 "다음 달엔 티거 만들래" 같은 이야기를 한다
- 회색 임시 부품이 줄어든다 (과목 편식 완화)

## 10. 확정 사항

1. 실존 전차 기반, 게임 에셋은 사용하지 않고 직접 단순화해 제작
2. 전투 요소 없음 (조립·도색·시운전까지)
3. 과목 = 전차 모듈 대응
4. 데이터는 몬스터 버전과 별도 저장 (연동 없음)
5. 주 사용 기기는 태블릿(네오탭 Z11 Plus), 웹호스팅 주소로 접속, 3D 품질 기본 낮음

## 11. 미결 사항

1. 1차 수록 전차 3종이 아이 취향에 맞는지 (4호 전차·T-34·M4 셔먼)
2. 제원 카드에 넣을 항목 범위
3. 전차를 탭했을 때의 반응 (포탑 회전 등) 횟수 제한
