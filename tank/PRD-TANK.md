## 0. 몬스터 3D 버전과 다른 점

| 항목 | 몬스터 버전 | 전차 버전 |
|---|---|---|
| 소재 | 오리지널 몬스터 | 실존 전차 (단순화한 로우폴리) |
| 제작 | 파츠 조합으로 새 생명체 만들기 | 실존 전차 1대를 골라 조립해 완성 |
| 일일 성장 | 크기·무늬가 조금씩 변함 | 부품 1개가 실제로 붙음 |
| 주간 진화 | 형태가 진화 | 조립 단계 해금 (하부 → 상부 → 무장 → 마감) |
| 과목 연결 | 몬스터 타입 (카드 아이콘) | 전차 모듈 (주포·엔진·무전기·장갑·승무원 장비) |
| 도감 | 몬스터 도감 | 차고 목록 (완성한 전차) |
| 장기 동기 | 새 몬스터 제작 | 등급 트리 해금 (초급 → 중급 → 현대전차) |
| 데이터 | `monsterPlanner3D` | `tankPlanner` (완전히 별도) |

핵심 규칙(한 달 완성, 주 80% 달성 시 다음 단계, 미션 1개 = 보상 1개, 퇴화 없음)과 **부모 모드 구성은 두 앱이 같다** (6.7절).

## 1. 한 줄 요약

전차를 좋아하는 초등 5학년이 숙제·공부 습관을 들이도록, 숙제를 완료할 때마다 부품이 하나씩 붙어 한 달에 실존 전차 1대를 완성하는 태블릿 웹앱.

## 2. 사용자

| 역할 | 설명 | 핵심 니즈 |
|---|---|---|
| 아이 (주 사용자) | 초5, 태블릿 사용, 전차 지식이 많고 월드 오브 탱크를 즐김 | 전차가 그럴듯할 것, 바로 시작할 수 있을 것 |
| 부모 (관리자) | 미션 등록·수정, 진행 확인 | 등록이 간단할 것, 아이 몰래 조정 가능할 것, **미션을 전부 직접 정할 수 있을 것** |

아이가 전차를 잘 안다는 점이 이 앱의 가장 큰 기회이자 위험이다. 실루엣이 어설프면 바로 알아채고 흥미를 잃는다.

## 3. 목표와 비목표

**목표**
- 아이가 매일 스스로 앱을 열고 미션을 시작한다.
- 숙제 시작까지의 망설임을 최소화한다 (버튼 하나로 시작).
- 한 달 단위의 뚜렷한 목표(전차 1대 완성)를 준다.
- 완성한 전차가 차고에 쌓이며 수집 동기를 만든다.

**비목표 (이번 범위 밖)**
- **전투·사격·적 등장.** 조립·도색·시운전까지만. 전투가 들어가면 숙제 앱이 아니라 게임이 되고, 아이가 숙제보다 게임을 하러 온다
- 월드 오브 탱크를 비롯한 게임의 모델·로고·UI·용어 화면을 그대로 가져오는 것 (실존 전차를 직접 단순화해 만든다)
- 외부 3D 모델 파일(glTF 등) 사용 — 라이선스·용량 문제. 기본 도형으로 직접 조립
- 여러 아이 계정, 기기 간 진행 동기화, 앱스토어 앱
- 숙제 내용 자체를 채점하거나 검사하는 기능
- 벌칙·감점·부품 회수 (의도적으로 넣지 않음)
- **앱이 스스로 미션을 만들어 내는 것** — 미션은 부모가 등록한 것만 나온다

## 4. 핵심 규칙

| 항목 | 규칙 |
|---|---|
| 완성 주기 | 한 달 = 전차 1대 완성 |
| 조립 단계 | 4단계: 하부 → 상부 → 무장·장비 → 마감. **토요일부터** 그 주 달성률(완료/계획)이 해금 기준(기본 80%) 이상이면 다음 단계. 판정은 주마다 한 번, 앱을 열 때 밀린 주를 몰아서 판정 |
| 일일 성장 | 미션 1개 완료 = 부품 1개가 전차에 바로 붙음 (하루치를 다 해야 붙는 방식 아님) |
| 단계 잠금 | 부품은 **현재 단계 것만** 순서대로 붙는다. 그 단계 부품을 다 붙인 뒤의 미션은 회색 부품 교체에만 쓰임 |
| 미달 주 | 다음 단계만 미뤄짐. 이미 붙은 부품은 사라지지 않음 |
| 미션 등록 | **부모가 전부 등록.** "매주 반복" 요일별 일정 + 필요하면 특정 날짜만 따로 수정. 비워 둔 날은 쉬는 날 |
| 하루 미션 수 | 부모가 정한 만큼 (하루 최대 5개). 고정된 "하루 미션 수" 설정은 없음 |
| 미션 시간 | 미션마다 5~60분 (5분 단위, 부모 설정). 아이는 집중 모드 시작 전에 20·30·40·50분 또는 부모가 정한 시간 중 고를 수 있음 |
| 과목 | 부모가 추가·이름 변경·삭제 (최대 12개). 처음 목록: 수학, 수학패드, 영어, 구몬, 기타 |
| 과목 = 모듈 | 과목마다 전차 모듈을 부모가 지정. 처음 연결: 수학=주포·조준, 수학패드=엔진·변속기, 영어=무전기·통신, 구몬=장갑·궤도, 기타=승무원 장비 |
| 회색 임시 부품 | 다음 부품의 모듈과 완료한 과목의 모듈이 다르면 회색으로 붙음. 나중에 그 모듈 과목을 하면 회색 부품 하나가 제 색으로 교체 |
| 해금 | 초급 1대 완성 → 중급 해금, 중급 1대 완성 → 현대 해금 |
| 기기 | 아이는 태블릿 한 대만 사용. 저장이 브라우저 안에 되므로 다른 기기에서 열면 진행이 따로 감. 기기를 옮길 땐 부모 모드의 내보내기/가져오기 사용 |

## 5. 전차 설계

### 5.1 수록 전차 (등급 트리)

| 등급 | 전차 | 해금 조건 | 모델 |
|---|---|---|---|
| 초급 | 4호 전차 (독일), T-34 (소련), M4 셔먼 (미국) | 처음부터 선택 가능 | 4호 전차만 완성. T-34·M4는 "모델 준비 중" |
| 중급 | 티거 I (독일), IS-2 (소련), M26 퍼싱 (미국) | 초급 1대 완성 | 준비 중 |
| 현대 | 레오파르트 2 (독일), T-90 (러시아), K2 흑표 (한국), M1 에이브람스 (미국) | 중급 1대 완성 | 준비 중 (중급 해금 전에는 목록에도 안 보임) |

- 한 달에 1대씩 고른다. 같은 전차를 다시 만들 수도 있다 (도색·마킹을 달리해서)
- 전차마다 부품 수는 비슷하게 맞춘다

### 5.2 조립 단계와 부품 (4호 전차 기준, 부품 44개)

| 주 | 단계 | 부품 수 | 붙는 부품 (순서대로) |
|---|---|---|---|
| 1주 | 하부 | 16 | 하부 차체, 보기륜 우 1~4 → 좌 1~4, 리턴 롤러 우·좌, 기동륜 우·좌, 유동륜, 궤도 우·좌 |
| 2주 | 상부 | 14 | 상부 차체, 운전수 전면판, 운전수·무전수 해치, 엔진 데크 좌·우, 앞 펜더, 포탑 본체, 포탑 경사판 좌·우, 포탑 수납함, 포탑 측면 해치, 큐폴라, 큐폴라 해치 |
| 3주 | 무장·장비 | 14 | 포방패, 주포, 머즐 브레이크, 차체 기관총, 안테나, 배기 머플러, 전조등, 공구함, 예비 궤도, 포탑 쉬르첸 좌·우·뒤, 차체 쉬르첸 좌·우 |
| 4주 | 마감 | — | 부품 대신 **미션 1개 = 꾸미기 항목 1개 해금**: 기본 도색 → 위장 무늬 → 마킹 → 완성 검수 |

- 카메라가 전차 우측을 보므로 우측 주행장치를 먼저 붙인다 (첫 부품이 바로 보이게)
- 부품이 붙을 때: 위·바깥에서 날아와 결합 + 금속 충돌음 + 화면 번쩍임 + 진동. 회색 부품은 둔탁한 소리
- 각 부품은 모듈이 정해져 있고, 미션 카드와 결합 알림에 모듈이 표시됨

### 5.3 꾸미기 (4주차 해금 + 완성 후 언제든)
- 기본 도색 4종: 독일 황색, 독일 회색, 소련 녹색, 미국 올리브 (전차 국가의 기본색 표시)
- 위장 무늬 4종: 단색, 삼색 위장, 겨울 백색, 디지털 위장 (캔버스 텍스처 1장)
- 마킹: 국적 마크, 부대 마크 3종(방패·화살·번개), 차체 번호 3자리 (화면 키패드로 입력 — OS 키보드 안 뜸)
- 회색 임시 부품에는 도색이 적용되지 않음 (과목 편식의 흔적으로 남김)
- 완성한 전차도 차고 목록에서 다시 도색·마킹 변경 가능
- (0.1의 "부속품 위치 선택"은 구현하지 않음 — 11절 미결)

### 5.4 완성 보상
- 시운전: "완성!" 1.6초 → 앞으로 2.5초·뒤로 2.5초 주행, 바퀴 회전, 포탑 좌우 선회 (약 5초, 건너뛰기 가능). 사격 없음
- 제원 카드: 국가, 연도, 주포, 중량, 최고 속도, 승무원 수, 생산 대수 + 월간 완성 배지 + "전 부품 정품 / 회색 부품 n개"
- 차고 등록: 남은 부품은 정품으로 자동 결합(완성 검수), 썸네일 캡처
- 다음 등급 해금 안내 → 다음 달 전차 선택 화면

### 5.5 그래픽 원칙
- 실루엣 우선. 디테일보다 **차체 비율, 포탑 형상, 보기륜 개수**를 맞춘다 (아이가 알아보는 근거)
- 로우폴리·모형 장난감 느낌. 사실적 질감 대신 깔끔한 단색 + 약간의 음영
- 궤도는 개별 링크를 만들지 않고 이어진 띠로 표현
- 배경은 단순한 차고 바닥 (소품 없음)

## 6. 화면

공통 규칙 (태블릿):
- 버튼·카드는 손가락으로 누르기 쉬운 크기 (최소 48px 이상, 간격 넉넉히)
- 가로·세로 모드 둘 다 대응. 가로에서는 전차 옆에 미션, 세로에서는 전차 아래에 미션
- 마우스 올림(hover)에 의존하는 기능 없음
- 화면 확대·축소, 위아래 튕김 막기
- 홈 화면 아이콘으로 열면 주소창 없이 전체 화면

### 6.1 차고 (홈)
- 3D 조립 중인 전차 (손가락으로 좌우 회전) + 전차 이름·단계 표시 ("2주차 · 상부")
- 오늘 미션 카드 → 각 카드에 "시작"(진행 중이면 "이어서") 버튼 하나, 과목의 모듈 배지와 시간 표시
- 미션이 없을 때: 한 번도 등록하지 않았으면 "아직 미션이 없어요 — 부모님이 등록하면 여기에 나와요", 등록은 했는데 오늘이 비어 있으면 "오늘은 쉬는 날"
- 이번 주 진행 바 (다음 단계까지 n개 남음) + 부품 진행 ("부품 12/44 · 다음: 보기륜 좌 3")
- 하단 버튼: 전차 바꾸기, 꾸미기, 차고 목록, 부모

### 6.2 집중 모드
- 시작 전: 미션 이름 + 시간 선택(20·30·40·50분 또는 부모가 정한 시간) → "시작"
- 시작 후: 큰 타이머. 시간이 끝나면 초록색 `+MM:SS` 초과 표시 + 차임 + 진동 (한 번만)
- **3D 렌더링 정지.** 전차는 정지 직전 프레임을 작은 이미지로 한쪽 구석에만 표시
- 타이머 도는 동안 화면이 꺼지지 않게 (Wake Lock, https에서만 동작)
- 타이머는 시작 시각 기준으로 계산 → 앱을 닫았다 열어도 이어짐. "나가기"하면 진행 중 상태 유지
- "완료" → 3D 재개 → 차고 → 부품 결합 연출 + 효과음
- 효과음은 첫 화면 터치 이후에만 울림. 소리를 못 내거나 부모가 효과음을 끄면 진동·화면 연출로 대체

### 6.3 전차 선택 (월초)
- 이번 달에 만들 전차 고르기. 등급·국가·연도·별명 표시
- 모델이 없는 전차는 "모델 준비 중", 잠긴 등급은 "초급 1대 완성 시 해금" 표시
- 가로: 카드 가로 나열 / 세로: 세로 나열

### 6.4 꾸미기
- 3D 미리보기 + 기본 도색·위장·마킹 선택 (큰 썸네일 버튼)
- 4주차에 해금되지 않은 항목은 잠금 표시
- 차체 번호는 화면 키패드로 입력

### 6.5 완성 연출
- 4주차 조건 충족 후 차고 진입 때 전체 화면 연출 → 시운전 → 제원 카드 → 차고 등록 (5.4절)

### 6.6 차고 목록 (도감)
- 완성한 전차 카드 (썸네일, 이름, 국가, 완성 월, 도색·번호)
- 등급별 전체 목록 (미완성·잠김은 실루엣)
- 완성 카드를 누르면 3D로 보기 + 도색 변경 (변경 시 썸네일 다시 캡처)

### 6.7 부모 모드 (몬스터 앱과 같은 구성)
- 비밀번호 6자리 (화면 키패드). 처음에는 두 번 입력해서 정함. 해시로 저장
- **미션 등록**
  - [매주 반복] [날짜별] 전환. 처음 들어오면 "매주 반복"부터
  - 매주 반복: 월~일 요일별 미션 목록 → 매주 자동으로 나옴
  - 날짜별: ◀▶로 주 이동, 한 주 7일이 한 화면에. 날마다 "반복" 또는 "이 날만" 표시, 고친 날은 "반복으로" 버튼
  - 날마다 "+ 과목" 버튼으로 추가, 분량 메모, 시간 −/+ (5분 단위), 삭제. 이미 한 미션은 "완료 ✓"
  - 한 주 도구: 지난주 미션 복사, 반복 일정으로 되돌리기, 이번 주 비우기
  - 오늘 미션을 고치면 차고에 바로 반영 (시작·완료한 항목은 유지)
- **달성률**: 오늘·이번 주·이번 달 %, 최근 7일 막대, **과목별 최근 4주** (연결된 모듈과 회색 부품 수), 전차 정보(단계·부품 수·완성 대수)
- **설정**: 과목 관리(이름·모듈), 단계 해금 기준(50~100%), 타이머 기본값(5~60분), 효과음 켜기/끄기, 3D 품질(높음/낮음), 성능 표시 켜기/끄기, 비밀번호 변경
- **테스트·초기화** (설정 탭 아래): 오늘 미션 다시 만들기, 이번 주 달성 처리(다음 단계), 현재 단계 부품 전부 결합, 모든 데이터 지우기(비밀번호 유지)
- **데이터**: 파일로 저장 / 글자로 보기(복사용) / 파일 또는 붙여넣기로 가져오기

## 7. 기술

**구성**
- Three.js r180 (ES 모듈). `three.module.js` + `three.core.js` 두 파일을 같은 폴더에 두고 불러옴 → CDN 의존 없음
- 그 외 외부 라이브러리 없음. HTML/CSS/JS는 index.html 하나에
- 전차는 기본 도형(상자, 원기둥)을 코드로 조합. 외부 모델 파일 없음
- 3D 캔버스는 배경 레이어, UI는 그 위 HTML 레이어
- 데이터 저장: localStorage 키 `tankPlanner` (구조 `version: 4`) — 몬스터 버전과 완전히 분리. 이전 버전 저장은 자동 변환 (예전 자동 과목은 "매주 반복" 일정으로 옮겨 흐름 유지)
- 효과음: Web Audio로 생성 (외부 파일 없음)

**배포·접속**
- GitHub Pages: `https://lprince98.github.io/3D_Scheduler_toSon/tank/` (첫 화면 `…/3D_Scheduler_toSon/`에서 전차·몬스터 선택)
- 홈 화면 추가 시 앱처럼 보이도록 manifest + 아이콘 + 전체 화면 설정. manifest scope는 `tank/` 폴더라 몬스터와 따로 설치됨
- 서비스워커로 오프라인에서도 열리게. 캐시 이름은 `tank-` 접두어, 같은 주소의 몬스터 캐시는 지우지 않음
- 파일을 고치면 `sw.js`의 `VERSION`을 올려야 태블릿이 새 버전을 받음
- 배포 절차는 README에 기록

**대상 기기 (성능 기준선)**
- 네오탭 Z11 Plus — 11인치 FHD, Helio G99 (Mali-G57 급 GPU), RAM 8GB, 안드로이드
- 보급형이므로 아래 성능 항목은 권장이 아니라 **필수 조건**
- 브라우저는 안드로이드 크롬 기준

**화면**
- 11인치 FHD (1920×1200) 기준, 가로·세로 모두 대응, PC에서도 깨지지 않게
- 뷰포트 설정으로 확대 금지, 안전영역 여백 반영
- 회전하거나 키보드가 올라올 때 캔버스 크기 자동 조정

**입력**
- 포인터 이벤트로 터치·마우스 동시 지원
- 펜(로랜텍 초미세 터치펜)은 정전식이라 손가락과 구분되지 않음 → 펜 전용 처리 없음. 버튼 크기는 손가락 기준 유지
- 3D 캔버스 위에서만 드래그 회전 처리, 나머지 화면은 평범하게 스크롤
- 길게 누르기로 뜨는 선택/확대 메뉴 막기

**성능 (필수)**
- 목표 30fps 안정 (30fps 상한)
- 폴리곤 예산: 전차 1대 약 4,000 삼각형 이하. 현재 완성 상태 + 마킹 약 2,840, 드로우콜 약 100
- 궤도는 개별 링크 만들지 않음. 같은 형태 지오메트리는 공유
- 실시간 그림자 사용 안 함 → 전차 아래 그림자 이미지 한 장
- 조명 2개 이하, 후처리 효과 없음, 반투명 최소화
- 픽셀 비율 상한 1.5. 품질 낮음 = 픽셀 비율 1.0 + 안티앨리어싱 끔 (기본값), 높음 = 1.5 + 켬
- 화면이 안 보이거나 집중·부모·차고 목록 화면일 때 렌더링 완전 정지
- 확인용 성능 표시(fps·삼각형 수)는 부모 모드에서 끌 수 있음
- 실기기로 10분 이상 켜두고 발열·프레임 확인

## 8. 개발 단계

| 단계 | 내용 | 완료 기준 | 상태 |
|---|---|---|---|
| 0 | 전차 1종(4호 전차) 3D 프로토타입 + 터치 회전 | **아이에게 보여줬을 때 무슨 전차인지 맞힌다.** 태블릿에서 30fps 유지 | 구현 완료 · 실기기·아이 확인 필요 |
| 1 | 전차 선택 + 차고(홈) + 미션 완료 + 부품 결합 | 아이가 전차 고르고 미션 3개 완료해 부품 3개 붙임 | 구현 완료 |
| 2 | 집중 모드 타이머 + 3D 정지/재개 + 결합 연출·효과음 | 타이머로 실제 숙제 1회 | 구현 완료 |
| 3 | 부모 모드 (등록·설정·달성률) | 부모가 한 주 미션 직접 등록 | 구현 완료 (0.3에서 몬스터와 같은 구성으로 통일) |
| 4 | 주간 단계 해금 + 도색·마킹 + 완성 연출 + 차고 목록 + 제원 카드 | 4주 완주 시나리오 동작 | 구현 완료 (테스트 버튼으로 확인) |
| 5 | T-34·M4 셔먼, 중급·현대 전차 모델 추가 | 해금 흐름 동작 | 남음 |

0단계 검증이 가장 중요하다. 아이가 전차를 알아보지 못하면 뒤 단계를 만들어도 소용없다. 여기서 실루엣을 고치거나, 안 되면 계획을 접는다.

## 10. 확정 사항

1. 실존 전차 기반, 게임 에셋은 사용하지 않고 직접 단순화해 제작
2. 전투 요소 없음 (조립·도색·시운전까지)
3. 과목 = 전차 모듈 대응 (과목과 모듈 연결은 부모가 설정)
4. 데이터는 몬스터 버전과 별도 저장 (연동 없음)
5. 주 사용 기기는 태블릿(네오탭 Z11 Plus), 웹호스팅 주소로 접속, 3D 품질 기본 낮음
6. 미션 1개 완료 = 부품 1개 즉시 결합 (하루치 묶음 보상 아님)
7. 미션은 부모가 전부 등록 (매주 반복 + 날짜별 수정). 앱이 자동으로 만드는 기본 미션 없음
8. 부모 모드는 몬스터 앱과 같은 구성
9. GitHub Pages 저장소 하나에 `monster/`, `tank/` 폴더로 나눠 배포

## 11. 미결 사항

1. 1차 수록 전차 3종이 아이 취향에 맞는지 (4호 전차·T-34·M4 셔먼)
2. 전차를 탭했을 때의 반응 (포탑 회전 등)과 횟수 제한
3. 하루치 미션을 다 했을 때 "오늘 조립 끝!" 같은 보너스 연출을 넣을지 (몬스터는 "오늘 미션 다 했어!" 문구만 있음)
4. 부속품(공구함·예비 궤도) 위치 선택 기능을 넣을지
5. 제원 카드 항목 범위 (현재: 국가·연도·주포·중량·최고 속도·승무원·생산 대수)
